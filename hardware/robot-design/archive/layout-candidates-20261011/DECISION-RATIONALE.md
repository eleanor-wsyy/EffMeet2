## 两个候选的本质差异

| | **方案 A · 板在底座** | **方案 B · 整板进头部** |
|---|---|---|
| 主板位置 | 底座 | 头部 |
| 跨轴线束 | **LCD FPC + 摄像 FPC + 电源 + 舵机 PWM + 键/灯**（多） | **电源 + 舵机 PWM + 键/灯**（少） |
| E04 / E05 | **必须买**（定长跨轴 FPC） | **删除** |
| **麦克风** | **固定在底座，拾音整间** ✅ | **随头转** ⚠️ 需改写 C06 |
| 头部重量/惯量 | 轻 | **重**，SG90 带载与 E10 供电须重核 |
| 过轴断帧/夹线风险 | **高**（两条 FPC 反复弯折） | 低 |
| 头部散热 | 无压力 | 主板在头，须核 |
| 装配复杂度 | 高 | 低 |
| 材料成本 | 多两条定长 FPC | 少 |
| 产品语义 | ✅ 麦不随头转，符合会议拾音 | ⚠️ 麦随头转，与既有结论冲突 |

## 决策判据（按权重）

1. **麦克风要不要随头转**——这是产品语义问题，不是工程问题。会议设备的麦应固定拾音整间；随头转会让转头动作改变拾音特性。
2. **过轴 FPC 能否接受反复弯折**——需要实测寿命，本轮只有 10 天，做不到 50 次循环以外的验证。
3. **SG90 带载余量**——方案 B 头部加重后，舵机啸叫/抖动若影响会议，即判不达标。

**倾向：方案 A。** 理由是判据 1 权重最高，且 A 的代价（多两条 FPC）是可控的采购与结构问题，B 的代价（麦随头转）是产品缺陷。
