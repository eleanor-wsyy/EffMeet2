**关键前提**：6 个 3MF 全部按 **256×256** 排盘 → **A1 / P2S / H2S / H2D 都能直接打**，只需在切片器里改机型。
**学校机器的价值 = 体积余量 + CoreXY 稳定 + 并行**，不是"只有它能打"。

### 分配原则

1. **大件、耗时件 → 学校**（并行出齐；A1 打它们最慢）
2. **小件、需迭代件 → 自有 A1**（打废即时重来）
3. **外露件必须黑料；壳内件急用时可用灰料**（颜色不影响尺寸）

## 3. 全局切片设置（所有盘通用）

| # | 位置 | **Bambu Studio 默认** | **改成** | 理由 |
|---|---|---|---|---|
| 1 | 强度 → 墙层数 | **2** | **6** | 名义壁厚 2.4mm ÷ 0.4 喷嘴 = 6 → 壁才是实心；2 圈会透光 + 内部纹路透到表面（鬼影） |
| 2 | 强度 → 稀疏填充图案 | **Grid** | **Gyroid** | Grid 交叉点重复挤出，大件喷嘴会刮擦填充面 |
| 3 | 强度 → 稀疏填充密度 | 15% | **不动** | 官方建议大件保持 15% |
| 4 | 支撑 → 启用 + 类型 | **关** | **开 + 树状 Tree** | 树状好拆、痕浅、省料 |
| 4b | 支撑 → 支撑外墙数 | 1 | **2** | 1 层墙太脆易断 |
| 4c | 支撑 → 顶面 Z 距离 | 0.2 | **0.25–0.3** | 更好拆 |
| 5 | 其他 → Brim 类型/宽度 | **自动** | **仅外侧 / 5mm** | 防大件翘边 |
| 6 | 耗材 → 热床温度 | 官方 | **60–65℃** | 防翘 |
| — | 质量 → 层高 | 0.20 | 外观 **0.16** / 机构 **0.20** | |
| — | 质量 → **首层层高** | 0.2 | **不动** | 首层要厚才粘得牢、容错平台不平 |
| — | 质量 → 接缝位置 | 随机 | **对齐** | 别用随机（满壳麻点）；斜拼接缝保持开启 |
| — | **腔温** | 自动 | **盯 <40℃**，超了手动拉前门缝 | H2 系列自动顶窗+排风联动，官方 PLA 腔温默认 0℃ |

**没列的都是不动的**——喷嘴温度/速度/风扇全按官方 PLA Matte 预设走。

### 机器相关

| 机器 | 注意 |
|---|---|
| **A1** | 无腔温，PLA 正合适；体积 256³，6 个盘都放得下 |
| **P2S / H2S / H2D** | 盘按 256 排的，改机型不会超界；**不用手动开门**（自动管理），但**广州室温 30℃ 上下要盯腔温** |
