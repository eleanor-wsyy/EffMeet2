# EffMeet2 线框原型生成器（Figma 插件）

在 Figma 里一键生成两屏线框原型（屏 1 会中·远程成员 / 屏 2 会后·观点地图），全部为**原生 frame + 文字图层 + auto-layout**，不是图片、不是 SVG 快照——每个元素都能在 Figma 里直接编辑。

## 使用方法（30 秒）

1. 打开 Figma 桌面端，进入一个文件（新建文件也行）
2. 菜单栏 → **Plugins → Development → Import plugin from manifest…** → 选择本目录下的 `manifest.json`
3. 再点 **Plugins → Development → EffMeet2 线框原型生成器** ——运行，两屏出现在当前页面并自动缩放到视野

## 之后

- 直接在这个文件里编辑，或全选两屏复制到团队 Figma 项目
- 字体：文本用 Inter 创建（Figma 内置）；中文会自动走系统回退显示。团队要统一字体：全选文字图层，批量改一次即可
- 每次运行会**再生成一套**两屏——重跑前记得删掉旧的

## 内容对应

- 屏 1 会中：状态栏 / 会议栏（录音中·离开）/ 现场转写条 / 现场画面（草图位+AI描述）/ 我的观点（两张状态卡）/ 候选确认浮层 / 底部语音发言主按钮
- 屏 2 会后：页头 / 统计条（3 观点·1 已回应·2 待核对）/ 三张观点卡（含回应摘要与查看原话）/ 导出按钮
- 文案与状态色以 `docs/product/EffMeet2_判断样例与提示文案_v1.md` 为准
