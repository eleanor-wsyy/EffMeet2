# EffMeet2 圆润转头版 · 安装指南

更新：2026-10-10（北京时间）。适用当前[BOM第12节](BOM.md#final-purchase-decision)与[PRINT_PLAN.md](PRINT_PLAN.md)：白/黑ABS-GF裸打，黑打印框露出LCD屏面，不喷漆、不切透明盖。

**本指南是待实物与可打印CAD落实后执行的装配顺序，不是现有模型已能装机的证明。** 当前固件仍是骨架；接线、螺钉长度、轴承配合和打印导出尚未冻结。可以先做到货检查、实物测量及合格的独立模块台架；尚缺条件的步骤按[测试指南](TEST_GUIDE.md)标记BLOCKED，不跳过后当整机通过。

## 最新外观同步：NOMI方向

本轮视觉目标改为球头＋近圆黑面板＋弱化短颈。仍用原矩形LCD/相机/转头架构，**不加圆屏、整片透明罩或喷漆**。组装时优先结合[外观与组装接口更新](EXTERIOR_ASSEMBLY_REVISION.md)：圆面板定位与真屏窗、LCD/相机内部支架、短颈内藏边、FPC先穿线后封头都尚待CAD落实，不得套用旧面板孔位。底座/供电/控制/受力检查沿用下文。

## 1. 开工前只检查这几件事

| 条件 | 必须拿到的内容 | 没有时怎么办 |
|---|---|---|
| 板卡/屏/相机实物 | 版本丝印、正反面、完整尺寸与连接器方向 | 不按AI图或芯片名接线/打印安装柱 |
| 接线表 | 实板供电、相机/LCD映射、按钮接法、舵机控制/共地方案 | 只做厂商允许的模块验证，不接未知GPIO |
| 机构实物 | 舵机含固定耳/舵盘、两只轴承及实测配合面 | 不把原占位尺寸当机加工配合 |
| 可打印零件 | 通过检查的STL/3MF、版本号、配合样片、零件清单 | 现有.blend只作布局参考；不要导出整场代理打印 |
| 软件 | 真实固件/官方独立示例及其配置说明、可用调试/停止入口 | 固件README不等于程序；软件mock不能替代机内功能 |

最低工具：卡尺、适合螺钉的起子、线标签、扎带/线夹、软片材、去毛刺工具；低压供电检测由熟悉电气的成员用合格工具完成。不为装配购买一套新机加工设备。

## 2. 安装安全与禁止项

- **断电插拔FPC、接插件和机械拆装。** 拉排线端部加强片，不拉细导体；先打开正确锁扣，确认接触面/深度后再锁，禁止反插后靠加电试运气。连接器的锁扣形式按实物说明，不从图猜。
- 使用成品合规低压电源；不改市电端，不将舵机接ESP32的3.3V引脚，不直接并联主板/舵机电源正极。共地与信号电平按已批准接线表。[A1][A3]
- 万用表测供电电压采用正确电压挡；不会用电流挡就不要直接测启动峰值，尤其不要用电流挡跨接电源两端。表笔/探针避免滑碰板卡相邻焊点。
- 手与线束远离带轮夹点；带电舵机不能用手强拧输出轴。刮/磨打印件和加装嵌件前，将电子件取下。
- 首次动作时留有能手动切断**舵机供电**的通路，不把“停止播报按钮”当已实现的机械急停；故障时先停止测试并断电。
- 不强压过紧轴承、不锤击舵机/屏幕、不以压紧螺钉把翘壳强行合上；发现配合差就修CAD/重打局部件。轴承压装如确需进行，应由熟悉该配合的成员执行，不能让装配力穿过滚动体。
- ABS-GF打印、嵌件与去支撑按学校设备/通风规则操作；不增加现场喷漆工序。

## 4. 按顺序安装；每步小测通过再往下

### 第一步：盘点、标号与实物测量

1. 对照BOM的E/M/C编号贴标签，记录版本、来源、实际尺寸和缺件。套装已含线/螺钉/麦/功放就不重复买。
2. 测主板焊接后总高、USB插头弯线空间、屏幕有效显示区、相机镜头突出、舵机固定耳/舵盘及轴承内外径/宽度。
3. 在尚未执行CAD改造前，将测量交给建模人，而不是自行认定parameters.json里的假设已验证。
4. 准备接线表：下表所有“待确认”完成后才接最终整机。

| 连接 | 必填记录 | 本指南明确不预设 |
|---|---|---|
| 主板↔LCD | 两端型号、触点/间距、接触方向、线长 | 用通用SPI屏/FPC直接替代 |
| 主板↔相机 | 模块版本、完整供电/信号映射、排线方向 | 按OV2640名字或信号表行数猜触点数 |
| 主板↔停止按钮 | 实板输入/板载键引出、逻辑、去抖行为 | 所有键是独立GPIO；按键自动硬件断麦 |
| 主板↔舵机信号 | 真正可引出的PWM资源、输出电平、接地点 | GPIO2空闲；NC针脚有可用排针 |
| 舵机供电 | 实物额定范围、端子极性、保护与断电点 | 任何MG90S仿品都可喂同一电压 |

### 第二步：裸板模块联调，不急着装壳

1. 在绝缘台面按厂商说明接主板电源和调试数据线；官方区分USB供电口与USB-UART口，数据线须能传数据。[A1]
2. 使用已确认固件/厂商独立示例，先确认启动日志和板卡状态，再分别测试显示、相机抓拍、双麦采集、扬声器播放。每次改变连接先断电。
3. 配套LCD通过对应FPC连接；官方示例的两板叠装是验证办法，本产品的分离/跨轴布线要另外确认。[A2]
4. 接按钮/状态灯后验证输入和实际事件一致；未实现则留下BLOCKED，不用眼睛亮了代表软件功能都完成。
5. 舵机用独立安全台架小范围控制，先不接带、不托头。其极限、供电及命令映射按实物校准。[A3]
6. 记录[测试T01–T11](TEST_GUIDE.md#test-cases)，哪些是板卡示例、哪些是真实项目功能分开写。

### 第三步：关键配合样片与打印件检查

1. 按打印方案，先用A1 PETG做1:1尺寸/配合试片，再用H2S正式ABS-GF做同位置试片；不能用PETG配合结果代替ABS-GF孔径。
2. 正式件检查裂纹、翘边、残留支撑、毛刺、功能孔和可拆接缝，尤其核对孔与真实麦克风/接口位置。去毛刺后吸/刷净碎屑，电子件装入前再清洁。
3. 用实板无电试放，安装柱不顶元件，屏框不挡显示，盖板无需强压可合上；未安装FPC时仍需检查插头空间。
4. 螺钉/嵌件长度按真实接收件决定；螺钉不得进入板上元件/屏背。使用热装嵌件时在电子件安装前完成，温度按材料/嵌件方案，不在本指南给统一值。

### 第四步：组底座受力结构（断电）

1. 先装轴承座、两个实物轴承、必要隔圈/止挡，再装空心转动连接件；采用已核定的分体夹紧/轴肩方案。旧模型的BEARING代理没有完整固定结构，不能按一个圆柱推测装法。
2. 检查轴向保持和轻转顺畅；不能靠拧紧压死两轴承消间隙。
3. 固定舵机架与舵机本体，固定耳受力正常；暂不装同步带。打印主动轮借助已核实的原配舵盘/接口固定，不强造花键。
4. 主板上安装柱、扬声器和密封片入位，保证前向出声通道；麦声孔对应实板双麦，密封材料不堵孔。实际安装顺序以能使用起子/插线为准，必要时可拆小支架，而不是粘死。
5. 底座盖暂不最终锁紧，留出轴承、带和供电排查通道。检查[T12](TEST_GUIDE.md#test-cases)。

### 第五步：确定正向，再连接传动

1. 舵机仍无传动/无头部，使用已验证控制方法将其设置到允许行程的中间位置，记录该命令。不要默认固定脉宽就是这只实物的机械中点。
2. **舵机断电后**安装舵盘/主动轮；如果安装时使舵机状态变化，拆开传动回到无负载中位重新校准，不带电强拧。
3. 将头部连接盘置于设计正向，装从动轮与同步带；本轮1:1只是设计路线，实际中心距、齿数、带长和张紧以CAD/实物为准。
4. 带不能松到跳齿，也不能张紧到轴承卡滞/架变形。初次只允许小角度、低速；确认机械和软限位后才扩至±45°目标。
5. 建立“实测头角↔实际命令”的标定表；测试T13/T14通过前，不能进入自动连续运动。

### 第六步：头部器件、短颈与活动线束

1. LCD先固定到头部内部可拆支架，再校准圆形黑面板的矩形真屏窗深度；玻璃不作承重面，圆面板不能削切屏有效区。实际相机/排线空间确认后才装面板。
2. 相机固定到圆面板上方的内部接收结构，滑盖与LCD支架互不干涉；装滑盖并验证开/关、视场和镜片间隙，线接触方向依接线表。
3. LCD/相机线通过中央允许的空心路线，两端分别固定，活动段留出左右运动余量；线夹只固定该固定的段，不粘死弯折段。
4. 关闭舵机供电并解除传动约束后，轻移可自由活动的头部/连接件检查路线；不要拖动已连齿轮舵机强行扫角。若不能解除则按小步低速控制检查，手不要进入夹点。
5. 装头到连接盘，确认重量由支撑机构承受；内藏式短颈边缘/白壳与固定盖有真实运动间隙，不为隐藏转轴缩掉原活动线空间。只有位置动画不能算通过。
6. 开盖状态按T14/T15逐步验证，确认屏/相机与机构同时正常后再封盖。

### 第七步：按钮、灯、足垫及封盖

1. 装黑按钮帽，按钮松开时不常压；盖板合上后的按压效果重新测。LED先直接出光，不为了效果图硬加光学扩散件。
2. 线束整理到不妨碍带轮/开孔/盖缝的地方。后向电源/调试线有应力释放，不随头转、不压在脚垫下。
3. 硅胶足垫平整贴合；配重本轮不默认安装。
4. **所有电源断开**后合盖与紧固，不挤线、不顶屏；螺钉拧到稳固即可，不给未指定打印螺纹套用金属件扭矩。
5. 入壳后重做显示、抓拍、麦克风、播放、停止和转头；裸板通过不替代装壳通过。

### 第八步：整机联调与交付

按测试指南完成目标行程、50次扫角、30分钟运行、授权提醒/停止及故障检查。未通过项先修，不打“整体PASS”。保留硬件版本、接线表、CAD/打印版本、固件提交、控制标定和证据；不要把真实人声/现场人像未经同意推到公开GitHub。

## 5. 装配检查单

- [ ] 接线表有实物确认，不猜GPIO、触点或供电极性。
- [ ] 轴承/支架/连接盘是完成结构，不是占位代理；舵机不单独托头。
- [ ] 麦孔、出声孔、屏窗、镜头/滑盖、按键和USB口均真实有效。
- [ ] FPC三姿态不绷紧/夹磨，外部线从固定底座出去。
- [ ] 带和线缆不会互相卷入，手可安全断开舵机供电。
- [ ] 盖板无强压、按钮不常压、屏不受挤压、足垫不摇晃。
- [ ] 实物测试记录已填写；不能把本机mock或官方板卡示例填成项目硬件通过。
