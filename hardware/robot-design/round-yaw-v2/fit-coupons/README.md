# 配合样片 · 1:1 公差阶梯（供 A1 / PLA·PETG 试打）

**用途**：验「装不装得进、哪一档公差合适、装配顺序对不对」。**不验最终材料强度。**
最终公差要在正式材料（PLA Matte）上再打一组同尺寸复验。
生成脚本：`generate_fit_coupons.py`（Blender 无头，`blender --background --python generate_fit_coupons.py`）。

尺寸来源：`BOM.md` §12.2 —— M02 轴承 6806 = **内径 30 / 外径 42 / 厚 7**；M01 舵机 MG90S 本体 **22.8×12.2×28.5**；转轴名义外径 **46**；头-底座间距 **14**。

---

## 01_bearing_OD_ladder.stl — 轴承外圈压配（188×52×7）

四档 Ø42 孔，从左到右：

| 位置 | 孔径 | 用途 |
|---|---|---|
| 1（最左） | **Ø42.0** | 名义值，通常过紧 |
| 2 | **Ø42.2** | |
| 3 | **Ø42.4** | 通常最接近可用 |
| 4（最右） | **Ø42.6** | 偏松 |

**怎么判**：手压轴承外圈进孔。**能推进去、不晃、不裂**的最小那档就是设计值。
⚠️ **不许用锤子强装**——PLA/PETG 脆，强压会裂（`BOM.md` M04 明确要求分体夹紧/螺接，不做强过盈）。

## 02_bearing_ID_and_shaft_ladder.stl — 内圈/轴配合（208×52×7）

从左到右：

| 位置 | 孔径 | 用途 |
|---|---|---|
| 1 | **Ø30.0** | 轴承内圈名义 |
| 2 | **Ø30.1** | |
| 3 | **Ø30.2** | |
| 4（最右） | **Ø46.0** | **转轴名义外径校核** |

**怎么判**：Ø30 三档试轴承内圈 / 轴肩；Ø46 试转轴外径是否打得准。

## 03_servo_pocket_and_wall.stl — 舵机口袋 + 壁厚/孔质量（90×70×6）

| 部位 | 内容 |
|---|---|
| 左半凹槽 | **MG90S 口袋 22.8×12.2，深 5mm** |
| 凹槽两侧 | 舵机固定耳孔 **Ø3.2**（间距 32mm，**按实测再调**） |
| 右上一排 | 通孔阶梯 **Ø2 / Ø3 / Ø4 / Ø5 / Ø6** |
| 右下窄梁 | **2.4mm 名义壁厚**（看层纹与强度观感） |

**怎么判**：舵机能不能落进口袋、耳孔对不对得上、孔是否圆、壁厚梁是否透光/开裂。

## 04_shortneck_clearance.stl — 短颈裙边间隙（Ø58×14）

外径 Ø58（= 46 轴 + 两侧各 6 壁）、内孔 **Ø46**、**高度 14 = 头-底座真实间距**。

**怎么判**：套在转轴上看 14mm 这段里裙边能不能藏住、又留出诚实间隙（见 [`../MODELING_BRIEF.md`](../MODELING_BRIEF.md) §1.5：装饰裙边必须与底座有可见间隙，不许焊死、不许为好看缩间距）。

## 打印参数（PLA / PETG 通用起点）

| 项 | 建议 |
|---|---|
| 层高 | 0.2mm |
| 墙 | 3–4 |
| 填充 | 20–30%（样片不需要实心） |
| 支撑 | 不需要（全是通孔/开口朝上） |
| 朝向 | **平放**，孔轴朝 Z |
| 材料 | 今晚用手上的 **PETG** 即可 |
