# 面板三点固定 R1 候选（2026-10-15，未合并）

## 要解决的问题

canonical v6只有Ø106面板与头壳接收唇，没有明确面板锁壳结构。本候选提供可拆卸承力连接，不靠胶水承力、脆性卡扣或强过盈。

- 左右两点在头中心相对x=±48.5、z=0mm；下方一点x=-16、z=-45mm，错开原头部线夹。三个孔均沿Y轴。
- 黑色面板各加Ø3.4通孔；灰色头壳内增加三个接收柱及与原接收唇连接的径向肋。
- 螺钉从正面拧入；M3六角螺母从头内径向侧装进捕获袋。螺母先装，再预装屏/摄像头，再合面板；需验证螺母不掉落及工具可达。
- M3×12×3、M3螺母×3仅是**包络预算/取样候选**，不是供应商CAD或采购放行。头Ø5.5×3、螺母对边5.5厚2.4也必须按实物回填；螺母袋对边5.7、深2.8为打印样片起点，非认证公差。
- 正面会增加三处螺钉。若采用本候选，渲染必须保留；不能继续用无螺钉脸表示R1。

- production/geometry-review.json：局部拓扑、名义干涉和保护范围检查。
- 初次拆卸图移动了原生宿主而未同步Boolean工具，造成假缺口；失败图仅保留本机，不上传。正式拆卸检查使用03中完整评估网格。
- production/geometry-review-attempt1.json：保留第一次失败；底部中间柱碰头部线夹，已局部移位。不把失败记录抹成PASS。

## 合并条件

先看[INTERFACE_GATES](../../INTERFACE_GATES.md)的FACE-01与LCD-01：真实螺钉/螺母、局部样片、螺母工具空间、拆装、LCD孔位/深度。通过后将候选参数进入唯一parameters并正式build_v6，再重建模型/STL/排盘/渲染及审计。当前31件正式源未变，不能仅换两个STL便宣称整套哈希一致。

局部网格与名义预算检查不证明强度、打印公差、扭矩、疲劳、跌落或硬件功能；制造/硬件/最终设计放行仍false。购买件代理和Boolean工具不导出为打印件。
