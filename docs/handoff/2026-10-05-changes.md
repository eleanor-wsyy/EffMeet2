# 2026-10-05 修改清单

本清单覆盖本次会话中的实现与文档整理。工作区为无 `.git` 的文件夹，未提交到远端。运行步骤、配置、复现与后续工作见 [交接记录](2026-10-05.md)。

## 新增实现

| 文件 | 目的与行为 |
|---|---|
| `services/relay/protocol.py` | EFMA 24 字节帧头与 PCM 编解码；检查流、长度、序号、采样位置、回绕；重复帧忽略、有限补静音 |
| `services/relay/asr.py` | FunASR offline WebSocket 适配，最多 30 秒音频、30 秒调用超时；不持久化原始 PCM |
| `services/relay/media.py` | 受控上行、播放握手、逐帧 ACK、回执顺序、停止；每次最多一个 20ms 帧待 ACK |
| `services/relay/tts.py` | 通过固定 PowerShell 内容调用系统语音，生成临时 WAV，验证格式并读取 PCM |
| `services/relay/synthesize.ps1` | Windows System.Speech 合成内容；文字、输出路径通过环境变量传入 |
| `services/controller/bench.py` | 分析任务、媒体绑定、命令领取与回执；任务网络 I/O 在 SQLite 事务外；启动时取消中断任务 |
| `services/controller/bench.html` | 本机台架页面，支持任务轮询、本人决定、停止、事件与原文记录 |
| `scripts/run_bench.py` | 统一台架启动入口，默认 8768、独立 bench 数据库、单 worker |
| `scripts/bench_audio.py` | 合规 WAV 上行及下行播放器；支持模拟音频汇，真实输出依赖 sounddevice，尚未硬件验收 |
