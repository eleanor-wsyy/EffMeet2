# PLATE-CARD · TMP-FIX-P29B_BLACK_016（P29 耳槽咬边返修）

> 2026-10-19 · 返修轮 2：FITFIX 盘的 P29 核心板仍「插不稳、松松垮垮、宽了」。
> 本盘只含 P29 一件（P15/P17/P26 上一轮已处理）。

## 根因与修复（build_v6.py）

**根因不只是槽宽，是耳槽根本没咬住板边。** 板宽 28.3（板边 x=±14.15），原耳槽内口在 x=15.05，离板边差 **0.9mm**——62.6mm 高的板只有底部 10mm 插座定位，上方全程无导向，怎么插都晃。

| 问题 | 根因 | 修复 |
|---|---|---|
| 插不稳 / 松垮 | 耳槽内口 15.05 距板边 14.15 差 0.9mm，板边根本没进槽 | 耳轨加宽内移（3→4.6，中心 ±(bw/2+1.7)），**耳槽内移咬住板边**：槽 0.7 宽，中心 ±(bw/2−0.25)，板外缘 **0.6mm 咬入槽内**，槽底距板边 0.1 |
| 槽宽了 | 底槽 X 旷 0.3/边、Y 旷 0.1/边 | 底槽 **28.5×1.7**（bw+0.2 / bt+0.1），与耳槽外壁 x=±14.25 对齐；Y 旷 0.05/边 |
| 底槽侧壁被耳轨填死 | 耳槽 Z 原从 91.5 起，盖不住底槽下沿 89.5 | 耳槽 Z 下延到与底槽底齐平（62 高，89.5 起），插到底无 2mm 台阶 |

不动：M3 孔（x=±10）、neck 孔、bevel=.6、耳轨高度。

## 打后检验（对应检验单 P29 节）

1. **插到底**：核心板从上往下落，板边进两侧耳槽、板底坐进底槽到底，不强压。
2. **不晃**：插到底后手推板边缘，全高不松垮、不咔哒响；拔出要有轻微摩擦感。
3. **尺寸**：底槽宽 28.5±0.1、槽宽（Y）1.7±0.05；耳槽口能看见咬进板边约 0.6mm。
4. **对孔**：2×M3 对 P23 头底柱不别劲（M3×6 从托架底锁入）。

## 不要

- 不要把耳槽锉宽回 2.2 旧尺寸（一锉宽就回到晃）。
- 板实测厚度 <1.6 仍轻微松 → 贴薄胶带垫片，**不重打**；先把板边厚（卡尺）报回来。
