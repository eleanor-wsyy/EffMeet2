# 第一部分 · 美学不变量（**禁止改动**）

以下逐条摘自已认可的 NOMI 方向审美契约。**建模时逐条对账，任何一条不满足即打回。**

## 1.1 头部形态

- 近球形、轻微压扁的柔软头部，名义 **150 × 128 × 144 mm**
- 白 / 米白柔和外壳，**真实球面侧体量、圆剪影**
- **禁止方脸颊、方形侧壁**
- 分模缝细、零件边界极少
- 头部几何可极轻微朝上，但**不得增加任何俯仰机构**
- **禁止**：椭圆肖像框、圆角方屏、巨大白额头上的小黑药丸

## 1.2 面部语言（这是审美核心）

- **Ø104–108 mm 圆形黑面板**，居中偏前，周围只留克制的白壳边
- 必须读作「球头上的一个黑圆」，**不是**显示屏、**不是**圆角矩形监视器
- 圆面板是**哑光打印炭黑板**（PLA Matte 裸打），**不是**圆屏、**不是**玻璃罩、**不是**光学透明片
- 中央是**真实矩形 LCD 贯通窗**；屏面接近齐平，矩形边是**低对比细缝**，近看才隐约可见
- **禁止**：粗凸起的矩形边框、大面积高光圆片、曲面玻璃、宣称"完美 OLED 黑"

## 1.3 眼睛

- **只有两只**，在矩形 LCD 有效区**内**（不得溢出 49mm 屏宽）
- 暖白色、柔和弯月形闭眼/微笑，或简单直立小椭圆，表情松弛
- **眼睛是视觉焦点**——不是"小平板贴在大盘子上"
- **禁止**：嘴、文字、其他 UI 元素

## 1.4 摄像头与隐私

- 小镜头 + **物理滑动遮罩**，位于圆面板内**上部居中**
- 低对比黑细节，融入深色板；镜头近看可见，滑盖齐平
- **禁止**：明显方块徽章、把摄像头移到白额头、为视觉隐藏而删掉隐私操作

## 1.5 转颈（短、藏）

- **极短居中 yaw 接头**，轴外径名义 **46 mm**，头-底座真实间距 **14 mm**
- 克制的嵌套壳/领口 + 阴影间隙，把转轴**藏在球头下缘**
- 装饰裙边**必须与固定底座有诚实间隙**——不焊死、不悬空飘头
- **禁止**：高白管/黑管、为藏转轴而缩小真实机械间距、把裙边与底座粘连成环

## 1.6 底座

- 软圆白椭圆鹅卵石，**180 × 164 × 76 mm + 2mm 黑硅胶脚垫**
- 产品总高约 **222 mm**；**头部明显比底座窄**
- 平滑宽肩、下缘圆角，**有实质内部体积**
- **禁止**：薄的 NOMI 车机垫、花瓶细腰、第二层叠底座
- 保留既有上盖/杯体细缝，可拆修

## 1.7 开孔与细节

- **扬声器**：直接开在下前白壳，**3–4 条短槽、宽约 35–40 mm**，**无对比色喇叭徽章**
- **麦克风**：小而安静的开孔
- **停止键**：前肩部**小齐平帽**
- **状态指示**：**微小暖珊瑚色短划**（在底座）——不是环形灯带、不是 RGB 灯带
- **外供电**从**后部固定底座**进入，**无可见乱线**
- 硅胶脚垫薄、黑、大部分隐蔽

## 1.8 材质与质感

- **灰 + 黑，未喷漆哑光 PLA Matte**，裸打，**全 14 件同一种料**
- 真实细聚合物纹理 + 细微规则层纹
- **禁止**：绒面 / 石膏 / 水泥质感
- 圆面板的反光**只应来自里面的矩形 LCD**——不得把打印面做成/画成光学玻璃
- **PLA Matte 热变形约 55℃**：结构设计不得依赖高温工况；散热缝与内部风道仍按 §第四部分 保留

# 第三部分 · 工程变量（本次真正要改的）

## 3.1 因换主板而变

| 项 | 原（Korvo） | 新（微雪 ESP32-S3-CAM-OV3660） | 对建模的影响 |
|---|---|---|---|
| 主板 | Korvo-2 V3.1（底座） | 微雪单板（含摄像头） | 板体尺寸/孔位/高度全变，**预留盒重做** |
| 屏 | 乐鑫 Korvo-2-LCD 2.4″（有效区约 49×37mm） | 微雪 18PIN FPC 屏（2.0″ 或 2.8″） | **圆面板 Ø104–108 与中央矩形窗必须按新屏重算**；1.2 的面板语言保持不变 |
| 摄像头 | 外接 OV2640，可自由定位 | **板载 OV3660，镜头位置由板决定** | **面板上部开孔坐标迁就实板**，不得为对称好看挪孔 |
| USB | Micro-USB | **Type-C** | 底座侧面浅凹槽**重开**（1.7 的位置语言不变） |
| 舵机 PWM | 可能要 E13 扩展板 | LEDC/RMT 直出 | E13 删除，内部空间释放 |
| 电池 | 无 | **新增 3.7V 锂电** | 底座内部容积/重心重算 |
| 音频 | ES7210/ES8311/NS4150B | **相同芯片组** | 麦/扬声器接法可迁移；**AEC 必须重测** |

## 3.2 因布局 A/B 而变（二选一，见 `layout-options/`）

| | **A · 板在底座** | **B · 整板进头部** |
|---|---|---|
| 头部腔体 | 只装 LCD + 摄像头（轻） | 装主板 + LCD + 摄像 + 麦 + 扬声器（重） |
| 底座腔体 | 主板 + 电源 + 电池 + 扬声器 + 舵机 | 舵机 + 电源 + 电池 |
| 跨轴通道 | **LCD FPC + 摄像 FPC** + 电源 + PWM + 键灯 | 只剩电源 + PWM + 键灯 |
| **麦克风位置** | **底座上缘**（1.7 的"安静开孔"在底座） | **头部**（随头转，须改写 C06） |
| 扬声器位置 | 底座前下 | 可能上移至头部 |
| 散热 | 无压力 | **需加强**（背部细缝 1.7 保留，内部加散热路径） |
| 头部重量 | 轻 | **重**，须复核 SG90 带载 |

**美学不变量在 A/B 下都不变**——只是开孔的**归属件**（头壳还是底座）不同。

# 第五部分 · 建模作业约束（按 AGENTS.md）

- 保留模型**原生 Screw/Boolean 控制**、分件与姿态依赖
- 新建模遵循适用 Blender 技能；不以预览动画代替固件验收
- `parameters.json` 与现有 `.blend` 的旧检查证据**不改写**；新参数另记并标 `unverified`
- `manifest.json` 的 `stage / manufacturing_ready / hardware_validated` **保持 false**
- 不导出伪参数 CAD（不把三角网格换后缀充当 STEP）
- **导出白名单**：只导出已完成结构的零件；排除 MAINBOARD/LCD/CAMERA/SERVO/BEARING/SPEAKER 代理、KEEP_OUT 与布尔控制

## 建模顺序

1. **先无电测件**：新屏总厚度/有效区、板载镜头突出量、FPC 出口方向、Type-C 凸出量
2. **圆面板 + 矩形窗**（审美核心，先定死）
3. 头部腔体（按 A 或 B）
4. 短颈 + 转轴接收面（14mm 间距、46mm 轴径）
5. 底座杯体 + 上盖
6. 受力件（轴承座/舵机架/轮毂/带轮）
7. 小件（滑盖/按钮帽/线夹/声学通道）
8. 更新 `parameters.json`（新参数标 unverified）
