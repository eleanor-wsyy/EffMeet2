# v4 · 最少操作打印方案（PLA Matte／布局A）

更新：2026-10-11。采购以 [BOM §12](BOM.md#final-purchase-decision) 为准；当前采用GOOUU已下单套装，外置双INMP441／MAX98357A／TP4056；扩展板未测，不计入容纳结论。当前模型和渲染入口见 [v4](revision-20261011-nomi-layoutA/README.md)，安装接口见 [EXTERIOR_ASSEMBLY_REVISION](EXTERIOR_ASSEMBLY_REVISION.md)。

**灰PLA Matte机身＋黑PLA Matte面板／机构／小件，裸打。** 不喷漆、不打磨补土、不退火、不切透明板、不采购圆屏。打印件仍需少量去支撑／去毛刺和螺接。

本方案**不是已经存在的可打印文件或制造放行单**。旧 stl/ 和 build_print_parts.py 留作历史草案，不能代表本轮接收面／新屏窗／新轴承路线；ABS-GF是已取消的旧基线，不再据此选喷嘴／温度。

## 1. 先打什么

1. **自有A1＋已有PETG**：1:1孔径、轴肩／D接收、舵盘、屏窗薄边、滑槽／按钮样片；不必先打全壳。
2. **A1＋正式PLA Matte**：重验上述配合和一块外表面样片。PETG试片不能代替正式料公差。
3. 实板、显示线束和摄像FPC、承重接收、支架／夹持座都锁定后，才打印全壳与机构。
4. 大壳按实际预约去学校H2D／H2S；不能未经切片和机时确认承诺“一天出齐”。A1可作重打备选。

## 3. 切片起点

- 普通0.4mm喷嘴、官方对应机器PLA Matte配置；外观曲面0.16mm、隐藏件0.20mm作为样片起点。
- 名义壳壁2.4mm，新增头底接收3.2mm；受力肋、螺接和孔补偿由实际结构决定，不靠高填充率掩盖缺少承重路线。
- 必须在切片预览检查：支撑可取、桥接／悬垂、最小壁、孔／槽贯通、接触疤位置、法兰层向、首层和杯底。
- 两颜色分盘，避免逐层换色；不假装FDM打印框是透明玻璃面板。
- 耗材密封防潮；出现潮湿迹象按厂家说明干燥，不沿用ABS-GF的80℃烘料流程。PLA无需为本任务额外购买硬化喷嘴或腔温设备。
- 环境温度、受力蠕变及30分钟运行后温升需实测；本轮无切片时间／重量和未做打印验收，禁止高温暴晒。

## 4. 放行清单

只有同时满足以下条件才生成正式STL／3MF：

- 实板、屏厚、相机、舵盘／耳孔、电池、轴承和两条FPC定义回填参数。
- 轴承夹持座／底座承力路径、轴肩／轴向锁定、齿形、止挡、所有可拆螺接和电子支架已建成。
- 五外观件网格检查＋全件安装／干涉／工具空间＋打印支撑可取检查通过。
- 1:1正式料样片确认，使用真实丝杆／螺母／嵌件尺寸，不能把名义孔径当实际公差。
- 导出只含真实打印零件，排除硬件代理、带轮包络、KEEP_OUT、布尔控制、眼睛／灯光表现、相机／地面。
