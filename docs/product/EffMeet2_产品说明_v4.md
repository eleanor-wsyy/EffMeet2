## 【外层 · 海报语】

**在线，不等于在场。**

我们做了一个帮线上的人"坐回桌边"的东西——一台守在会议桌边的桌面机器人。

**它替你看。** 白板上的草图、摊开的图纸，随手一拍，原图直接到你手机上——不用再问"你们说的是哪一张"。

**它替你开口。** 它一直安静听着。当它发现你的观点被讨论淹过去了，它不替你喊——先悄悄问你一句："要我提醒大家吗？"**你点头，它才转过头去**，对现场说："刚才线上提到的那个想法，要不我们回应一下？"

**它替你记住。** 散会不用翻聊天记录。打开软件，观点地图一目了然：聊了什么、谁持什么观点、哪些问题待回应——点一下，回到当时的原话。

它的分寸感：

- 你不点头，它不开口
- 拿不准的事，它宁可不问
- 它说的每句话，都能回到一句你的原话
- 想让它安静，按一下就行

**在线，也在场。**

## 【内层 · 职责与边界】

### 谁使用

有固定讨论节奏、线上线下并存的小团队。首发验证场景：校园科研组与课程项目组（3–6 人混合讨论）。不面向大型会议室与任意第三方会议平台。

- **远程成员**（核心服务对象）：任意设备打开软件即可看图、发言、决定是否请求提醒、核对记录
- **现场成员**：正常讨论，机器人只在被授权时插一句话
- **主持人**：绑定设备、发起会议，握住静音与停止的最终控制权

### 职责分工

| 角色 | 职责 |
|---|---|
| 机器人（现场的身体） | 桌面宠物形态；机内拾音、按需抓拍、经授权的短提示、状态呈现；静音/停止键即时生效。不做判断，不替任何人发言 |
| 服务后端（统一的账本与编排） | 转写、证据链、确认门控、模型调度（千问/DashScope）。路线 A（参赛 Demo）：承载于电脑伴侣应用；路线 B（最终形态）：机器人 Wi-Fi 直连云端，去电脑化 |
| 软件入口 | 手机、平板、电脑、网页，同一套功能：入会、看图、确认、观点地图 |
| 人 | 保留全部决定权；可校正归属与记录 |

### 首版边界

- 保留：固定机身、Wi-Fi、机内拾音与播放、按需抓拍、观点地图
- 后置：机器人独立算力（完全离线自治）、自动定位、额外轴运动、第三方会议平台兼容

### 工程红线（与外层"分寸感"一一对应）

| 红线 | 外层说法 |
|---|---|
| 无确认不播报 | 你不点头，它不开口 |
| 不确定则弃权（不产生候选事件） | 拿不准的事，它宁可不问 |
| 无原文证据不标"被忽视" | 每句话回到原话 |
| 重复命令不重复播报（幂等） | — |
| 候选 120 秒未确认自动取消 | — |
