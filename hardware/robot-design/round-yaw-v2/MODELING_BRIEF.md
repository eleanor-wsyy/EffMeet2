# 第一部分 · 美学不变量（**禁止改动**）

以下逐条摘自已认可的 NOMI 方向审美契约。**建模时逐条对账，任何一条不满足即打回。**

## 1.1 头部形态

- 近球形、轻微压扁的柔软头部，名义 **150 × 128 × 144 mm**
- 灰色PLA Matte柔和外壳，**真实球面侧体量、圆剪影**
- **禁止方脸颊、方形侧壁**
- 分模缝细、零件边界极少
- 头部几何可极轻微朝上，但**不得增加任何俯仰机构**
- **禁止**：椭圆肖像框、圆角方屏、巨大白额头上的小黑药丸

## 1.2 面部语言（这是审美核心）

- **Ø104–108 mm 圆形黑面板**，居中偏前，周围只留克制的白壳边
- 必须读作「球头上的一个黑圆」，**不是**显示屏、**不是**圆角矩形监视器
- 圆面板是**哑光打印炭黑板**（PLA Matte 裸打），**不是**圆屏、**不是**玻璃罩、**不是**光学透明片
- 中央是**真实矩形 LCD 贯通窗**；屏面接近齐平，矩形边是**低对比细缝**，近看才隐约可见
- **禁止**：粗凸起的矩形边框、大面积高光圆片、曲面玻璃、宣称"完美 OLED 黑"

## 1.3 眼睛

- **只有两只**，在矩形 LCD 有效区**内**（不得溢出 49mm 屏宽）
- 暖白色、柔和弯月形闭眼/微笑，或简单直立小椭圆，表情松弛
- **眼睛是视觉焦点**——不是"小平板贴在大盘子上"
- **禁止**：嘴、文字、其他 UI 元素

## 1.4 摄像头与隐私

- 小镜头 + **物理滑动遮罩**，位于圆面板内**上部居中**
- 低对比黑细节，融入深色板；镜头近看可见，滑盖齐平
- **禁止**：明显方块徽章、把摄像头移到白额头、为视觉隐藏而删掉隐私操作

## 1.5 转颈（短、藏）

- **极短居中 yaw 接头**，轴外径名义 **46 mm**，头-底座真实间距 **14 mm**
- 克制的嵌套壳/领口 + 阴影间隙，把转轴**藏在球头下缘**
- 装饰裙边**必须与固定底座有诚实间隙**——不焊死、不悬空飘头
- **禁止**：高白管/黑管、为藏转轴而缩小真实机械间距、把裙边与底座粘连成环

## 1.6 底座

- 软圆灰色椭圆鹅卵石，**180 × 164 × 76 mm + 2mm 黑硅胶脚垫**
- 产品总高约 **222 mm**；**头部明显比底座窄**
- 平滑宽肩、下缘圆角，**有实质内部体积**
- **禁止**：薄的 NOMI 车机垫、花瓶细腰、第二层叠底座
- 保留既有上盖/杯体细缝，可拆修

## 1.7 开孔与细节

- **扬声器**：直接开在下前白壳，**3–4 条短槽、宽约 35–40 mm**，**无对比色喇叭徽章**
- **麦克风**：小而安静的开孔
- **停止键**：前肩部**小齐平帽**
- **状态指示**：**微小暖珊瑚色短划**（在底座）——不是环形灯带、不是 RGB 灯带
- **外供电**从**后部固定底座**进入，**无可见乱线**
- 硅胶脚垫薄、黑、大部分隐蔽

## 1.8 材质与质感

- **灰 + 黑，未喷漆哑光 PLA Matte**，裸打，**全部打印件同一种料**（件数以拆分结果为准）
- 真实细聚合物纹理 + 细微规则层纹
- **禁止**：绒面 / 石膏 / 水泥质感
- 圆面板的反光**只应来自里面的矩形 LCD**——不得把打印面做成/画成光学玻璃
- **PLA Matte 热变形约 55℃**：结构设计不得依赖高温工况；散热缝与内部风道仍按 §第四部分 保留

# 第三部分 · 工程变量（本次真正要改的）

## 3.1 因换主板而变

| 项 | 原（Korvo） | 新（GOOUU ESP32-S3-CAM） | 对建模的影响 |
|---|---|---|---|
| 主板 | Korvo-2 V3.1（底座） | **GOOUU ESP32-S3-CAM（62.6×28.3mm，含 OV3660）** | 板体尺寸已知，**预留盒按此重做** |
| 屏 | 乐鑫 Korvo-2-LCD 2.4″（有效区约 49×37mm） | **2.8″ SPI TFT（240×320）** | **圆面板 Ø104–108 与中央矩形窗按 240×320 竖放重算**；1.2 的面板语言保持不变 |
| 摄像头 | 外接 OV2640 | **OV3660 经 FPC 接板** | 镜头为**独立模组**，安装位由我们定；面板开孔按实际安装迁就，不为对称好看挪孔 |

| 舵机 PWM | 可能要 E13 扩展板 | LEDC/RMT 直出 | E13 删除，内部空间释放 |
| 电池 | 无 | **3.7V 锂电 + TP4056 模块** | 底座内部容积/重心重算 |
| 音频 | ES7210/ES8311/NS4150B | **GOOUU 板无音频** → 外接 **INMP441×2 + MAX98357** | 麦/喇叭全部外接；**AEC 只能软件兜底，风险高于原方案** |

### 建模顺序（按风险）

1. **过轴通道 + 头壳 LCD/摄像支架**——先证布局 A 成立
2. 底座杯体（主板/电池/扬声器/麦孔布局）
3. 面板 + 短颈 + 上盖
4. 受力件（轴承座/舵机架/轮毂）
5. 小件

### 验收要点

| 项 | 通过标准 |
|---|---|
| **过轴 FPC 寿命** | 连续 50 次 ±45° 转向无断屏/断帧/断线（**第一验收项**） |
| 夹线 | 转动全程不夹线、不磨线 |
| 转向 | 1–2s 单次、头角误差 ≤3°、无啸叫影响会议 |
| **麦克风拾音** | **底座固定双麦**，1m 正常说话可转写、3m 小声触发 AGC |
| AEC | 重测（换板必做）；初赛不阻塞，决赛 11.5 前必须 |
