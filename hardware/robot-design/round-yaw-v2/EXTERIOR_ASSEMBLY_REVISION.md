# NOMI方向外观与组装接口同步说明

更新：2026-10-10（北京时间）。用户要求保留现有方案，只让外观更靠近蔚来NOMI，并要求组装方案同步更新。**本文件是外观/装配接口提案，不是已完成的CAD或实机装配验收。**

## 1. 当前方向与不变项

本轮转向“近球形头部＋圆形黑色面板＋简洁眼睛＋隐藏感短转颈”。前一轮白色大脸颊/小横窗只是中间候选，不再作为当前视觉目标。

**保持不变：**

- 外包络目标180×164×222mm，头部150×128×144mm；固定底座180×164×76mm＋2mm脚垫，不能把底座压成NOMI车载安装薄垫。
- Korvo主板在底座、普通2.4英寸矩形LCD和摄像头在旋转头部；原主板/屏/相机接口不换，双麦与扬声器配置不增加。
- 独立轴承承重、侧置微型位置舵机与1:1传动路线、左右各45°目标；不换无刷机构，不加俯仰或连续360°。
- A1 PETG关键试片→H2S白/黑ABS-GF正式件；不喷漆、不切透明板、不采购圆屏/AMOLED。
- 原BOM的功能项、数量与核心选型不增加；已有实物依然先盘点和验证。当前parameters.json、.blend和旧检查证据不改写，不借它们声明新外观已验证。

## 2. 参考什么，不照搬什么

参考：[蔚来官方ES6页NOMI栏目](https://www.nio.cn/es6)与[官方近景](https://cdn-public.nio.com/www-nio-cn/sheng-ji-ang-ran-ling-gan-ji-fa/es6-2025/cockpit/carousel-screen-04-desktop.jpg)。近景中的圆头、圆面部和短连接关系作为造型依据。

不照搬其品牌、车内安装、显示器材、驱动性能或制造工艺。NOMI的“脸”效果不能用来证明我们的小屏可变成圆形显示区。

| E02 LCD | 矩形屏保持，眼睛简洁，画面背景与黑框尽量接近 | LCD独立装在内部支架，不让玻璃承力；显示窗深度可用局部支架/垫片校准到接近齐平 | 真实玻璃外形/厚度以实物为准；反光和黑色差异不假装完全消失 |

| C01短颈外观/M02/M04支撑 | 外部连接缩短视觉存在感，保留真实14mm间隔和转轴目标 | 使用现有短颈外观件轮廓/内藏边，不新增与底座粘连的环；承重仍由连接件→轴承座→底座传递 | 白/黑颈件以本轮图与材料分批决定；±45°及支撑/排线间隙必须CAD复核 |
| E04/E05/M07排线 | 仍跨固定底座与旋转头部 | 先穿线再装接收件，两端固定、弯折区不固定死；所有新内藏边去锐角 | 隐藏颈不能挤占活动线空间，不能缩孔来换好看 |
| C01底座/C05扬声器 | 保留既有容量，前部短槽融入白壳 | 槽孔是真实出声口而非额外喇叭徽章；内部扬声器保持安装位/密封要求 | 不为低矮感缩掉板卡、轴承或舵机空间；槽形/开孔率和声腔另测 |
| E11/C04按钮 | 小齐平帽，整洁低对比 | 帽与实际开关行程/盖板孔配合，手能按到，松开不常压 | 仍停止播报，不是急停/硬件断麦 |
| E12/C04状态灯/C06麦孔 | 细小真实状态窗与拾音孔 | 避开面板装饰/盖缝，按实板位置设计通道；不被新肩部/内藏边盖住 | 灯与实际事件一致；双麦固定在底座 |

## 4. 头部与线束的同步安装顺序

1. **无电测件**：LCD装配总厚度、屏有效区、相机总尺寸/镜头突出、FPC出口方向、面板/壳口实际尺寸。CAD缺这些时只做试片，不打完整正式壳。
2. **先支架、后面板**：LCD先在内部可拆支架定位；相机支架与上部空间确认，连接处避开LCD角点/插座。
3. **先穿线、后封头**：已核接法的FPC在断电时通过允许的中央路线穿入，留活动段并固定两端；接收件/内藏边不能封死检修路径。
4. **装圆面板/滑盖**：黑面板装到头壳定位面，LCD窗口尽量齐平但不压玻璃；滑盖的开关/遮挡独立测。使用螺钉，不用粘死来掩盖窗口错位。
5. **接头与支撑**：维持原中位、传动、轴承承重顺序；头壳/短颈内藏边在左45°/0/右45°都不接触固定盖。
6. **最后合底座盖**：模块和活动线测试通过后再合盖，检查按钮、麦通道、出声槽、灯和后向供电线。

底座、主板、轴承、舵机、脚垫步骤沿用[安装指南](ASSEMBLY_GUIDE.md)，无需为了新造型重新换电气方案。

| 既有件 | 材料/流程 | 本轮CAD需调整 |
|---|---|---|
| 头壳 | 白ABS-GF，保留可拆入口 | 球形侧面/近圆前口、面板接收面、LCD/相机支架位置及打印方向 |
| 面板 | 黑ABS-GF，单色打印 | 圆轮廓、矩形真屏窗、相机/滑盖开口和隐藏紧固 |

| 底座杯体/上盖 | 白ABS-GF，保持既有容量 | 声槽、按钮/麦/LED的实际孔位与通道，仍可拆 |
| 支架/连接件/带轮 | 黑ABS-GF | 跟随实物轴承/舵盘尺寸，不因效果图随意移动驱动轴 |

不新增喷漆、整面透明罩、激光切割、多色逐层换料或机加工必需件。圆形黑面板的反光只应来自里面的矩形LCD，不把ABS-GF打印面画/做成光学玻璃。

## 6. 对测试指南的增量要求

- **T04**：圆面板上仍能看到LCD全部有效区；灰阶/黑背景、正常光照检查屏与打印黑框色差及窗口接缝，记录真实效果，不强称“无缝OLED”。
- **T05/T06**：镜头改在圆面板上部后，检查视场无遮挡、滑盖开/关及固定牢度；遮住镜头不影响屏/线束。
- **T12/T14/T15**：内藏短颈/新口边不得擦碰、夹线；各姿态及50循环必须重新检查，不能复用旧图或一次正向静态结果。
- **T07/T08/T17**：声槽、肩部和通道若改变，入壳拾音/播放要重测；不移动实板麦孔来迎合图上对称装饰。
- **T24**：检查球头/圆面板定位、可拆修、边缘毛刺与底座稳定；不以涂料修补装不上的接口。

其余业务授权、真实回执、停止、供电、故障恢复与AEC仍按原26项测试执行，记录模板不增删ID，默认仍NOT_RUN。
