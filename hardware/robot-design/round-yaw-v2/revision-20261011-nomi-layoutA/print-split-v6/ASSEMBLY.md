## 0.6 今天的两件应急（P02 裂 / P20 立柱断）

### P02（G3p 裂）
- **先干装两半对位**：中心 **Ø44 座圈必须完整**；接缝涂 CA/环氧，压重 30min；外面贴胶带/夹子。
- **加固（推荐）**：从顶板**垂直往下**钻穿接缝、进下圈壁，**4×Ø2**，插一段耗材当定位销，再涂环氧；比只靠胶稳得多。钻时避开 Ø44 座圈和 4 个 P01 螺钉孔；孔要落在 3mm 圈壁内。
- **圈碎缺**：用**上半（顶板）**当座，P14 法兰直接坐在上面；三点热熔胶/胶带定位；若下圈也碎，用 **3mm 厚临时环**（纸板/PLA，OD≈147、ID≈44）垫在 P01 口上；底部用 **5mm 泡棉块**做临时硬挡。
- **座面找平**：胶固化后用直尺/砂纸把 P14 法兰座面找平；法兰不能翘，否则转头会晃。
- **不要**用大量 502 灌缝（脆、流进孔）；**不要**用热熔胶做结构（会蠕变）。
- 重打（今天不追）：正打（接缝圈朝下）→ 树支撑 + **顶距 0.2** + 支撑密度 15–20% + 过支撑降速 50%；或加 0.5mm 接缝倒角；灰料先烘干。

### P20（INTERN2 立柱断）
- 立柱=螺钉座，断了不影响开关；**底座+开关口袋直接热熔胶点固在杯内壁键位**；P19 键帽照装。
- 重打（今天不追）：5mm brim、**Z-hop 0.4**、最小层时间 8s、风扇 100%、立柱区降速；最好在 `build_v6.py` 立柱根部加 **1.5mm 圆角/撑筋**。
- **不要**用支撑包住立柱（会粘死）。
- **预设**：不要用旧的 `EffMeet2-v6 0.20 H2S`（`wall_loops=6` / `support_on_build_plate_only=0`）；按 [PLATE-CARD-P02P20](plates-merged/PLATE-CARD-P02P20.md) 新建 0.16 预设。

## 1. 底座电子（P01 内 · 参照 parts_img/P01.png）

1. **麦克风**：INMP441 放入 P32 胶座腔，**焊盘凸边朝腔缺口方向**（放反盖不进）；模块底面小孔对 P32 底 Ø6 声孔。P32 底 rim 涂热熔胶（**只涂外圈，别堵声孔**），罩住 P01 内壁 Ø2.4 声孔按压 10s。**左右各一，L/R 看丝印勿反。**
   - 判据：模块在腔内不晃、声孔同心（目视）。常见错：胶挤进声孔→堵孔。
   - **先量模块厚度**：P32 腔 **19×19×4.2 深**；超过 4.2 会凸出，凸出朝底座内，不顶杯壁。P32 缺：麦双面胶贴壁对声孔。
2. **功放**：MAX98357A 放 P17 托盘、两安装孔对 **12.6 距 M2 柱**（Ø4.5 / 孔 Ø1.7，M2×4 手拧）；接线：**Vin 5V、GND、LRC、BCLK、DIN、GAIN、SD**；扬声器接**差分 +- 两焊孔，勿共地**。判据：板贴平、排针侧不顶围边、线不绷。
3. **扬声器**：放入 P16 环内**振膜朝前**；缘垫 EPDM 圈；焊片朝后接线。判据：手按不晃、振膜不碰壁；总厚 ≤17。常见错：垫圈压到振膜→破音。
4. **舵机**：MG90S 滑入 P15 耳架（**口袋 13.7 = 12.5+1.2**）、耳孔对架孔；用**舵机自带 M2 螺钉**，手带紧不锁死（留前后 ±2mm 张紧）；舵盘不装。判据：能滑动、不晃。
5. **停止键**：开关入 P20 口袋；**无论 P20 在不在，都热熔胶点固**（口袋只有 1.8mm 深）；两脚引线接空闲非启动 GPIO；P19 键帽后装。
6. **供电**：E17 USB-C 输入板放 P18T 腔、扎带勒紧；连接器对 P01 后容差窗（13.5×9.5）。
   - **E17/P18T 缺**：5V 从后窗/颈孔引到**头部核心板**；底座只留舵机 5V；**共地**。核心板在头里，不在底座，别再写“底座 Type-C 直供”。
   - 判据：插拔线板不位移；舵机电源与核心板分开，不共 3.3V。

## 2. 传动 / 轴承（底座中心 · 参照 P05/P06/P11.png）

1. **P05 落底**：P05 四腿坐在 P01 底；**4×M3×55–60 从 P06 耳孔穿入，过 P07–P10、P05 四腿，底部 M3 螺母**。先干装量高度：堆叠约 **56mm**，M3×70 会多出约 **14mm**，剪短/加垫，别让螺丝顶桌面。
2. **下 6806 入座**：轴承平放座口，**拇指只压外圈**均匀加力；手感阻力线性增大、最后“咚”到底、外圈端面与座口齐平=到位。
   - **紧**：停，砂纸/打磨鼓修孔，勿敲勿压内圈。
   - **松**（能晃/一放就掉）：生料带缠座孔 1–2 圈或薄垫片；仍松，少量 CA/环氧点外圈（永久）。
   - 先用梯条样片 01 预判哪格轻压入。
3. P07–P10 四支柱立四角（方向不分）。
4. **上 6806 入 P06** → P06 盖柱顶 → **4×M3×55–60 对角序 1-3-2-4**：每颗拧到手指拧不动再 **+1/8 圈**即停。常见错：过拧→PLA 白痕/蠕变松脱。
5. **P11 空心轴**自上穿两轴承内圈：顺滑下落=配合对。
   - **D 平面朝上**（P03/P14 侧）；底端圆面朝下。**先确认轴承坐在圆段，不坐在 D 平面上**；若平面伸进轴承位，用薄垫片/胶补偿。
   - 紧=砂纸磨轴；松=生料带缠轴 1–2 圈；不磨轴承。
6. **P12 开口夹环**：先掰开套入轴底，两夹块合拢，**M3×10/12 穿夹块锁紧**；锁到“手转轴有阻尼但不卡”。**不要用顶丝顶轴**（会顶出坑）。
7. **P03 64T** 套轴上端 D 平面；**M2 顶丝**（孔 1.5–1.6）锁 D 面；先通紧定孔毛刺。P04 同理；P04 缺=舵机端空着。
   - GT2 带到货再套 P03/P04 + P15 张紧；未到=手转演示，不要硬拉舵机。
8. **P13 限位摆臂**装 **P03 下方、同一段 D 平面**；底端只装 P12。手转轴：**±45° 顺滑、48° 碰硬挡**；P02 缺时用 **5mm 泡棉块**做临时硬挡（别手扶）；量角器核对。

## 4. 合婚 / 穿线（顺序已修正 · 参照 P14/P30/P31.png）

> **顺序铁律：线 → P02 → P14 → 头 → 最后 P24。** 旧版顺序会卡死：P02 的 44mm 孔套不过 P14 的 58mm 法兰；线在 P14 之后穿不进。

1. **先穿线**：9 根**裸线**（5V/GND/3V3/BCLK/WS/MIC SD/AMP DIN/SERVO PWM/KEY）先套 PET 护套，穿 P11 Ø22 孔（**中心 Ø10 禁入区留空**）。**先不压端子/不焊头**，过孔后再焊。
2. **P02 上盖**：44mm 中心孔套过线束，合 P01；限位块对 P13；**4×M3×8/10 对角锁**。P02 裂/缺见 §0.6。
3. **P14 短颈**：40mm 管套过线束/轴，法兰落在 P02 上；D 孔对 P11 D 平面；**M2 顶丝**锁；**4×M3×8/10** 拧法兰。
4. **头**：P23 落 P14 法兰，**4×M3×8/10 对角**；线束从 P11 上端进 P14 内孔，再从 P23 底部 18.3mm 孔进头；接核心板。
5. **最后压前脸**：把 P24+P25+LCD+P26 组件压进 P23 前脸（**锥面自锁**）；P25 **4×M2.5**；P27/P28/P19。**P24 没有面板螺钉，不要打孔；松动就三点少量热熔胶/胶带。**
6. **P30/P31 线鞍**：P30 底座侧、P31 头侧；扎带**绕槽不扎紧**；余量判据=**头转到 +45° 时线束仍能塞进一根手指**。
7. 手转 ±45° 二十次：线不绷不磨、FPC 不断帧、无异响。

## 5. 上电前（今天只做 1–4）

1. 万用表通断档：5V 与 GND 不短、各信号线对地不短。
2. 上 5V：无发热无异味 → 屏亮/摄像出图/串口日志正常。

## 6. 常见坑（速查）

- **顺序**：线 → P02 → P14 → 头 → P24；P02 在 P14 之前，P24 最后。
- **P24 没有面板螺钉**：锥面自锁 + P25 压框；不要按 R1 打孔。
- **P05/P06 是同一组 4×M3**：不是“落底一组 + 长螺钉一组”；M3×55–60，底部螺母。
- **P03/P04 顶丝 M2**：孔 1.5–1.6，不是 M3。
- **P13 在 P03 下方 D 平面**：底端只装 P12；P11 D 平面朝上。
- **松配合**：生料带/薄垫片/少量 CA；紧=砂纸/打磨鼓修塑料；轴承不敲、不扩、不磨内外圈。
- 螺钉对角序、贴合即停 +1/8 圈；PLA 过拧必蠕变。
- 麦随头转=产品缺陷；麦永远固定底座。
- FPC 裁了=报废；14mm 是硬约束。
- 胶只涂 rim/点固，别堵声孔别灌腔；P20/P32 都要胶。
- 替身颈（PETG）与正式颈（黑）D 面/顶丝通用，换装只卸顶丝。
- 扎带扎紧=线束疲劳断；留 1 指。
- **P02 裂**：先胶接/上半做座；**P20 立柱断**：底座+热熔胶，别等重打。
