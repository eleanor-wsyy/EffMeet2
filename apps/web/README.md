# EffMeet2 手机用户端（本地演示版）

`apps/web/` 现在是一个可以独立运行的单页 PWA，包含首页、会议、历史、我的四个主页面，以及加入会议、快速会议、预定会议、观点地图和会议详情。所有会议、观点、转写、AI 提示、额度与用户数据都由 `store.js` 在本地生成并写入 `localStorage`；不连接真实后端、音视频、语音识别、AI 服务、硬件、联系人、支付或云数据库。

## 运行

方式一（仓库根目录）：

```bash
python -m http.server 8000
```

打开 `http://127.0.0.1:8000/apps/web/`。

方式二（只运行用户端）：

```bash
cd apps/web
python -m http.server 8000
```

打开 `http://127.0.0.1:8000/`。

不要直接双击 `index.html`：ES module 和 Service Worker 需要 `http`/`https` 环境。支持安装到手机主屏；离线时只缓存静态界面，会议数据仍只在本机 `localStorage`。

## 页面与交互

- **首页**：v6 机器人渲染图、演示设备状态、电量、剩余 AI 额度、重新连接机器人、三个会议入口、扫码加入、即将开始的预约、最近会议。
- **加入会议**：会议号、昵称、麦克风权限、摄像头权限，保留原有入会校验。
- **扫码**：进入页面自动开启摄像头并识别二维码，识别成功后直接带入加入会议页；不再提供示例码和手动输入。
- **会议**：Zoom 式大头像舞台与头像条、腾讯会议风格的暖白底部控制栏（静音、开启视频、共享、参会者、更多，珊瑚橙高亮）、共享内容、实时转写、AI 提示、待确认列表、原图放大、观点地图。会中隐藏全局底部导航。
- **历史**：正式会议记录按时间倒序，支持主题搜索与“近 7 天 / 有待办”筛选。
- **详情**：会议纪要、观点图谱（按主题分组、发言者决定便签颜色、点击查看原话证据）、按时间顺序排列的完整转写。
- **我的**：昵称、套餐与额度、免费版/高级版对比、模拟升级、联系人（即将开放）、演示模式、重置演示数据、设置入口。
- **设置**：会议提醒、提示音、减少动画、语言说明、隐私与数据、清除离线缓存、关于。

## 数据与模拟边界

- 存储键：`effmeet2.local.v1`。`我的 → 重置演示数据` 可恢复初始示例；设置会随其他本地数据一起保存。
- 初始额度为 120 分钟、已用 38 分钟；结束正式会议会按分钟计入本地额度。高级版演示套餐为 600 分钟，不展示价格，不接支付。
- “进入演示模式”打开的会议标记为 `isDemo`，结束后只写入演示记录，**不会混入正式历史**，也不影响额度。
- 麦克风按钮只模拟授权结果；设备连接、电量、额度、AI 提示与机器人回执均为演示数据。
- 摄像头权限会请求本机授权。会议中的摄像头仅作**本机自预览**，不会传输给其他参会者；不可用时自动显示“模拟画面”。扫码页同样只在本机处理画面。
- 会议音视频传输、实时语音识别、真实 AI、机器人播报、联系人和云端同步都未接入，页面内均有“模拟/示例内容”标注。

## 测试

```bash
node --test tests/state.test.js
```

测试覆盖邀请链接解析、候选状态与时限、滑动判断、页面结构、PWA 资源、离线缓存和本地数据关联。

## 与原控制器工作台的关系

根目录 `services/` 的调试工作台仍保留，但 `apps/web/` 不再调用 `/api/*` 或 `/healthz`；本目录可以脱离控制器独立运行。若后续接入真实后端，可在 `store.js` 之上替换数据适配层，而无需改动页面结构。
