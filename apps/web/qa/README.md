# 用户端临时 HTTPS 真机验收（合成数据）

这个入口**不是正式部署**。只允许一个独立、临时的 mock 会议及 `remote_1` 身份访问；主仓库原来的主持人工作台、创建会议、上传发言等接口不向隧道开放。不要在此输入真实会议内容、真实成员信息或实际机器人凭据。只有本机测试机运行期间 URL 有效。

## 启动

在仓库根目录安装 `requirements-media.txt` 所列 Python 依赖；从 Cloudflare 官方发行版取得 `cloudflared-windows-amd64.exe`，放在被 Git 忽略的 `.local/tools/cloudflared.exe`。确认下载来源和签名/发行摘要，再运行：

```powershell
./.venv/Scripts/python.exe apps/web/qa/run_phone_preview.py
```

终端会输出以 `https://` 开头的 **PHONE QA HTTPS** 邀请地址、随机临时访问口令和合成会议 ID。在手机 Safari 或 Chrome 打开地址，先输入口令，再进入用户端。口令不要提交仓库，也不要公开转发邀请地址。首次使用时可以尝试添加到主屏幕。保持终端打开；`Ctrl+C` 停止隧道、网关和控制器，临时数据库随之销毁。每次重启地址、口令、会议 ID 都会变化。需要仅测试本机安全边界时运行 `--local-check-only`，这个 HTTP 地址**不能**作为手机麦克风 HTTPS 验收链接。

候选提醒使用 4 条人工合成发言；各候选初始有效期由原服务端控制为 120 秒。到期后允许本人显式重新校验，不会因为查看状态自动续期。如果需要演示初始待确认态，重新启动脚本并用新的链接；浏览器的旧标签页不要沿用。


## 当公网隧道被当前网络阻断：同一 Wi-Fi/手机热点的局域网 HTTPS

在 Windows 主机确认手机和电脑处于同一局域网，使用 `Get-NetIPAddress -AddressFamily IPv4` 找到当前私有 IP，然后运行（按本机 OpenSSL 路径调整）：

```powershell
./.venv/Scripts/python.exe apps/web/qa/run_phone_preview.py --lan-ip 192.168.43.25 --openssl "D:\Program Files\Git\usr\bin\openssl.exe"
```

运行时会输出 `https://<局域网IP>:8877/app/?meeting_id=...`、口令与本机的**公开测试根证书** `.local/phone-qa-cert/effmeet2-qa-root.cer` 路径。把 `.cer` 通过自己可信的文件传输方式传到手机，按手机系统的「安装 CA 证书/描述文件」流程安装；iOS 还需要在证书信任设置中显式信任该测试 CA。仅信任你亲自从本机取得、核对 SHA-256 指纹的测试证书；**绝不传输 `.key` 私钥**。证书最长 30 天，测试结束后从手机撤销信任并删除本机 `.local/phone-qa-cert`。只有完成信任，浏览器才会把此 HTTPS 视为可靠安全上下文；不要忽略证书警告继续做麦克风/PWA 验收。

这是**局域网**地址，手机断开该 Wi-Fi/热点或切换纯 4G 就不可达；4G 真机验收仍需可用的正式 HTTPS 服务或恢复隧道。Windows 公用网络防火墙可能阻断 8877 入站；先用手机实测，若无法连接，只添加限定该局域网、TCP 8877 的临时入站规则并在验收后移除，不要关闭整机防火墙。手机热点有时开启客户端隔离，届时改为同一普通 Wi-Fi 或可用公网测试环境。
## 真机检查与记录

- iOS Safari 与 Android Chrome 分别打开 HTTPS、输入口令、验证入会链接和昵称输入；拒绝麦克风后重试，检查授权提示是否符合浏览器实际行为。授权按钮仅请求权限，**不代表持续录音或发送音频**。
- 入会后验证会中页面、每个候选的「查看状态 → 请机器人提醒 / 不必提醒」、倒计时与到期重校验；确认其他候选未被连带改变。这里仅验证 mock 业务回执，**不是机器人现场实播**。
- 横滑进入观点地图，核对观点状态、证据与导出；刷新后使用当前邀请链接重新进入，确认已处理候选不被重复决定。
- 按浏览器提供的「添加到主屏幕」入口检查启动图标与页面；切换 4G、断网、再联网验证断线恢复。离线只能显示已缓存的静态界面，不能操作候选或获取新证据。分别记录机型、系统版本、浏览器版本、时间、步骤、截图和问题。

## 边界和团队联调

网关只监听 `127.0.0.1`，通过 HTTPS 隧道访问；随机口令、Secure/HttpOnly/SameSite Cookie、单会议路由白名单与单人 token 限制为测试防护，**不是正式用户认证**。Cloudflare Quick Tunnel 是临时第三方通道，可能因网络、客户端或服务状态不可用；不要用于正式数据。不要将隧道地址、口令或数据库写入 Git。

真实会议仍需成员提供会议服务/LiveKit 接入、浏览器音频发布链路、现场 AI 描述数据源、机器人播报及回执、会议结束事件和可持续的正式域名/身份认证。它们不能通过单人合成数据验收来宣称完成。真机检查必须由手持设备的人执行并记录；代码测试不能替代手机操作。
