# EffMeet2 v6 · 安装手册（2026-10-15 预写 · 按已打印件）

> 适用：v6 布局A2 已打印件（plates-merged 各盘）＋ BOM §12 采购件。
> 顺序总纲：**去支撑清点 → 底座电子 → 传动/轴承 → 头部 → 颈/合壳 → 穿线 → 上电前检查 → 26 项实机验收**。
> 纪律：麦克风**不随头转**（固定底座）；**禁止裁剪 FPC**；轴承/螺钉**不得强压强拧**；26 项测试见 [TEST_GUIDE](../TEST_GUIDE.md) / [TEST_RECORD_TEMPLATE](../TEST_RECORD_TEMPLATE.csv)，未测记 NOT_RUN。

## 1. 底座电子（P01 杯体内，麦不随头转）

1. **麦克风**：INMP441×2 装入 P01 后上壁袋，拾音孔对壁袋声孔；P21/P22 压圈胶固定。**左右勿反**（L/R 标记）。
2. **功放**：MAX98357A 入 P17 托盘，扬声器焊线接差分输出（**勿一端共地**）。
3. **扬声器**：入 P16 托架，朝前；EPDM/硅胶垫片垫缘，**不堵振膜/出声槽**。
4. **舵机**：MG90S 入 P15 耳架，张紧槽留 ±2mm 余量；舵盘先不装。
5. **停止键**：开关入 P20 托座（前肩），引线接空闲非启动 GPIO；P19 键帽后装。
6. **USB-C 输入板**：入 P18 托架，对 P01 后部 11.5×7 开口；5V≥2A 输入。
7. 核心板**不在底座**（v6 进头部），底座只留上述＋走线。

## 2. 传动 / 轴承（底座中心）

1. P05 承力塔落底，四柱螺钉固定。
2. **下 6806** 入 P05 座：只用手压/软垫轻敲至座底，**禁锤禁强压**；紧则报告。
3. P07–P10 四支柱立於下座四角（M3 穿过）。
4. **上 6806** 入 P06，P06 盖於支柱顶，**4×M3×70 贯穿**压紧上下座＋支柱；逐角对角交替拧至贴合，**勿过拧**（PLA 会蠕变）。
5. **P11 空心轴**自上穿入两轴承内圈；D 面朝驱动侧。
6. P12 下止推夹环抱轴底，顶丝/夹环螺钉锁（留转动余量按设计）。
7. **P03 64T** 套空心轴上端（M3 顶丝锁 D 面）；**P04 32T** 装 MG90S 舵盘口袋；**GT2 188 带**套 32T→64T，用 P15 张紧槽调至带不跳齿、轴不卡。
8. P13 限位摆臂装轴下 D 面，硬限位 48° 对 P02 限位块；手转头部确认 ±45° 软、48° 硬挡、不顶线。

## 3. 头部（P23 内，随头转）

1. **核心板**竖装入 P29 托架（FPC/USB-C 端朝上，上方留 10mm 调试空间），固定於头底。
2. **LCD** 贴 P24 面板背面：四孔对面板四柱（77×45），P25 后压框从后夹持螺钉锁（**勿压到排针/FPC**）。
3. **摄像头**入 P26 托架贴面板背面，镜头对面板镜头孔（中心=窗上沿+17）；**FPC 14mm 禁裁**，直线跨距 9.55 余量 4.45。
4. P24 面板装入 P23 前脸开口；**P27 导轨**贴面板前、**P28 滑片**入轨（滑动顺畅、打开位 x=11+）。
5. 屏排线/摄像 FPC 走头内杜邦净空 12mm，**不折死**。

## 4. 颈 / 合壳 / 穿线

1. **P14 短颈** D 孔套 P11 轴上 D 面，顶丝锁；颈法兰入头底接收座。
2. **P23 头**落於颈法兰＋头底接收座，螺钉固定（先穿线后封头）。
3. **穿线（约 9 根细软线）**：5V、GND、3V3、BCLK、WS、MIC SD、AMP DIN、SERVO PWM、KEY —— 穿 P11 空心轴 Ø22 孔（**Ø10 禁入区留空**），两端 P30（底座侧）/P31（头侧）线鞍固定；**束带绕槽、禁扎紧排线**，留 ±45° 宽缓弯折余量。
4. **P02 上盖**合於 P01 杯体：限位块对 P13；接缝圈螺钉锁；键帽 P19 装前肩键柱。
5. 头部转 ±45° 二十次，检查线束不绷不磨、FPC 不断帧。

## 5. 上电前检查

- 5V 输入→板供电正常；无短路发热。
- 麦/功放/扬声器/舵机/键/屏/摄像 接线对表（见 [GOOUU-BOARD-SPEC](../GOOUU-BOARD-SPEC.md) 引脚）。
- 头部手转顺畅、限位正确、线束余量够。
- 螺钉无过拧、轴承无异响、带不跳齿。

## 6. 实机验收（26 项）

按 [TEST_GUIDE](../TEST_GUIDE.md) 逐项跑，记录入 [TEST_RECORD_TEMPLATE](../TEST_RECORD_TEMPLATE.csv)；重点：50 次 ±45° 循环不断帧、30 分钟运行温升、AEC 边界、实体停止键、本人确认/真实回执。**缺 CAD/接线/固件记 BLOCKED，未测记 NOT_RUN，不得标 PASS。**

## 常见坑（对照 [PRINT-LESSONS](PRINT-LESSONS.md)）

- 轴承紧=报告，勿硬扩孔/强压。
- PLA 螺钉过拧会蠕变松脱→对角交替、贴合即停。
- 麦随头转=产品缺陷，务必固定底座。
- FPC 裁剪=报废，禁。
- 薄壁件（P21/P22/P27/P28）轻拿轻放，断了重打便宜。
