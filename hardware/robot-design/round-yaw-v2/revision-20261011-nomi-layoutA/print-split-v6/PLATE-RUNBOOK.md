## 2. 全局切片设置（所有盘通用）

| 项 | Bambu Studio 默认 | 改成 | 理由 |
|---|---|---|---|
| 墙层数 | 2 | **6** | 名义壁厚 2.4mm÷0.4 喷嘴＝6，壁才实心不透光 |
| 稀疏填充 | Grid 15% | **Gyroid 15%** | Grid 交叉点重复挤出，大件刮擦 |
| 支撑 | 关 | **开＋树状**，外墙 2，顶面 Z 0.25–0.3 | 树状好拆、痕浅 |
| Brim | 自动 | 仅外侧 / 5mm（大件） | 防翘边 |
| 热床 | 官方 | 60–65℃ | 防翘 |
| 首层层高 | 0.2 | 不动 | 厚首层粘得牢 |
| 接缝 | 随机 | **对齐** | 别满壳麻点 |
| 腔温（H2） | 自动 | **盯 <40℃**，广州室温高要盯 | PLA 热变形约 55℃ |
| 喷嘴温度/速度/风扇 | 官方 PLA Matte | 不动 | |
