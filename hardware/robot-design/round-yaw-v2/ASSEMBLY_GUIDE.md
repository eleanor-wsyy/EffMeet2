## 1. 开工前只检查这几件事

1. **实物尺寸已录入** `parameters.json`：微雪板体尺寸图、18PIN 屏接口定义、镜头突出量、Type-C 凸出量、MG90S 固定耳/花键、6806 轴承实测。
2. **配合样片已跑通**（`fit-coupons/` 四件），轴承座/轴肩/舵机口袋的公差档已选定并写回 `parameters.json`。
3. **正式 CAD 已导出**：仅导出已完成结构的零件（见 [PRINT_PLAN](PRINT_PLAN.md) §3.5 导出白名单），排除 MAINBOARD/LCD/CAMERA/SERVO/BEARING/SPEAKER 代理与 KEEP_OUT。
4. **材料到货**：PLA Matte 灰×2 + 黑×1；PETG 仅用于配合样片。
5. **工具**：十字/内六角、镊子、卡尺、去毛刺刀、M2.5/M3 螺钉与黄铜嵌件。

## 2. 安装安全与禁止项

- **断电装配**：穿线、接插件、封盖一律断电操作。
- **禁止强装**：PLA 偏脆，**轴承座必须分体夹紧/螺接**，不做强过盈压装、不做薄弹性卡扣；装不进就换公差档，不许锤。
- **禁止粘死**：所有定位用螺钉，不用胶粘掩盖错位。
- **禁止暴晒/高温**：PLA 热变形约 55℃，远离窗边暴晒与密闭高温环境。
- **禁止为好看牺牲功能**：不得缩孔、不得移麦孔、不得盖住声槽（见 [MODELING_BRIEF](MODELING_BRIEF.md) 红线清单）。

## 4. 按顺序安装；每步小测通过再往下

### 第一步 · 盘点、标号与实物测量

- 清点 BOM §12.2 的 30 项，标号归类；已买件与待买件分开。
- **实测并回填 `parameters.json`**：微雪板体实际长宽高/接头突出、屏总厚度与有效区、镜头突出量、Type-C 凸出量、MG90S 固定耳孔距与花键、6806 内外径实测。
- **小测**：所有实测值与 `parameters.json` 的 `unverified` 项逐条对得上，或更新之。

### 第二步 · 裸板模块联调，不急着装壳

- 微雪板上电、烧录骨架固件、串口日志无报错。
- 屏点亮、显示测试图；摄像头出图（esp32-camera 支持 OV3660）。
- 双麦拾音回采、扬声器放音、LEDC/RMT 出 PWM 驱动舵机。
- Type-C 供电与数据传输确认。
- **小测**：裸板状态灯进 idle；屏/相机/麦/喇叭/PWM 五项逐一有回执。**此步不过不装壳。**

### 第三步 · 关键配合样片与打印件检查

- 用 `fit-coupons/` 的四件样片确认公差档已选定（轴承外圈 Ø42.__ / 内圈 Ø30.__ / 轴径 Ø46.__）。
- 打印件逐件去毛刺、检查壁厚与孔是否圆；**PLA 件不许强压**。
- **小测**：轴承能手推入座、不晃不裂；舵机落进口袋、耳孔对位。

### 第四步 · 组底座受力结构（断电）

- 轴承座（分体夹紧/螺接）→ 6806 轴承 ×2 → 隔圈/止挡 → 连接盘。
- 侧置 MG90S + 舵机架 + 同齿数带轮 + GT2 带（1:1）。
- 承力顺序：**头部重量 → 连接件 → 轴承座 → 底座**；舵机只提供转向力。
- **小测**：手动转头 ±45° 顺滑，不顶挡、不夹线；松手不回弹卡滞。

### 第五步 · 确定正向，再连接传动

- 定义 0° 正向（面板正对前方），再装传动；软限位 ±45°、硬挡在外。
- **小测**：左 45° / 0° / 右 45° 三点到位，连续 5 次重复精度可接受。

### 第六步 · 头部器件、短颈与活动线束

- **先支架、后面板**：LCD 先在内部可拆支架定位；相机为板载，按实板坐标开孔定位，不为对称好看挪孔。
- **先穿线、后封头**：E04（18PIN）/E05（24PIN）在断电时穿过中央路线，**两端固定、弯折区不固定死**，留活动段。
- 内藏短颈/新口边去锐角；**不得挤占活动线空间、不得缩孔换好看**。
- 装圆黑面板（Ø104–108）+ 隐私滑盖；屏窗尽量齐平但**不压玻璃**。
- **小测**：左 45°/正向/右 45° 各静置检查，**无夹线、无断屏、无断帧**。

### 第七步 · 按钮、灯、足垫及封盖

- 停止按钮帽（前肩部小齐平帽）、状态灯导光窗（底座微小珊瑚短划）、双麦声孔通道、扬声器声槽。
- 硅胶脚垫 ≈2mm 贴底面。
- 最后合底座上盖；模块与活动线测试通过后再合。
- **小测**：按钮行程正常、灯与实际事件一致、声槽不堵麦孔、脚垫不挡散热缝。

### 第八步 · 整机联调与交付

- **连续 50 次 ±45° 转向**：观察不夹线 / 断屏 / 断帧 / 复位。
- **30 分钟组合运行**：记录板端压降、温升、连接与录音。
- 停止按钮确实停止；隐私滑盖可拨、不干涉。
- **AEC 重测**（换板必做；初赛路线 A 不阻塞，**决赛 11.5 前必须完成**）。
- **小测**：`TEST_RECORD_TEMPLATE.csv` 26 项逐条填实际结果与证据，未做的标 `BLOCKED`，不得标 `PASS`。
