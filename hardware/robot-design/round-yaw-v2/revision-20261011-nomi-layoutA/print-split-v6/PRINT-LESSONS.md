# 3D 打印教训集（2026-10-15 实战沉淀）

> 目的：把本轮开打踩过的坑记下来，**后面的人别重复犯**。每条=现象→真相→正确做法。
> 适用：EffMeet2 v6 打印执行（Bambu Studio + 学校 H2S/H2D/P2S + 自有 A1，PLA Matte 灰/黑）。
> 相关：[PLATE-RUNBOOK.md](PLATE-RUNBOOK.md) §5、[MEASURE-TODO.md](MEASURE-TODO.md)、[HANDOFF](../../HANDOFF.md) 顶部 10-15 节。

## 一、排机与耗材

1. **先问每种料有几卷，再排并行。** 现象：按"4 盘全并行"排好，结果黑料只有 1 卷 → 黑盘只能串行，排程作废。真相：一卷料同一时刻只能喂一台机。正确做法：排机前先确认灰/黑各几卷；黑 1 卷=黑盘串行，灰 2 卷=灰盘可 2 台并行。
2. **黑料紧张时，把"可灰"件改灰释放瓶颈。** 现象：黑盘 3 轮串行卡死。真相：PLATE-RUNBOOK 标注 B2 机构件"急用可灰"、B3 支架件"可灰"（壳内不可见，颜色纯外观）。正确做法：机构/支架改灰，用闲置灰卷并行；只把**外露件**（面板/短颈/滑盖/键帽）留给黑料。
3. **换料顺序：灰→灰→灰→黑，黑放最后。** 省一次洗喷嘴/换料停机。
4. **条件完全一致（颜色×层高×机器×支撑）的盘可以合并省机时。** 例：B2 机构 10 件 + B3 支架 6 件同条件 → 并成一盘 16 件。但**单卷串行时合并反而更优**（1 盘 1 次 setup vs 2 盘 2 次）；多机并行时才拆盘。先想清楚是并行还是串行再决定拆/合。

## 二、3MF 与切片

5. **3MF 只是几何起点，"不叫已切片"。** 现象：以为拖进 3MF 就能打。真相：plates/*.3mf 只含床面排布，不含机型/材料/支撑。正确做法：进 Bambu 必须手动选机型+耗材+设工艺；别把 3MF 当成品切片。
6. **喷嘴直径会过滤工艺预设下拉。** 现象：H2S 上找不到 0.4 的工艺预设。真相：H2S 默认喷嘴 0.2，下拉只显示 0.2 喷嘴预设，0.4 基的被隐藏。正确做法：先把「喷嘴→直径」改 **0.4**（学校是 0.4 硬化钢），下拉才出 0.4 预设。所有壁厚/墙层数计算都按 0.4。
7. **"空层无法打印"≠网格坏了。** 现象：切片报 P07–P10/P16"模型在X和Y之间出现空层，无法打印"，橙色一大片。真相：逐Z三角面跨距验证**无真空层**；实为薄于 0.4 喷嘴的薄鳍被切片丢弃。正确做法：别被警告吓停整盘；拆 **SAFE**(零警告)/ **THIN**(勾**检查薄壁**) 两盘，SAFE 先打，THIN 的薄鳍缺几道不影响结构主体。
8. **条件显示的参数找不到就别卡机时。** 现象：找不到「顶部Z距离」。真相：要先「开启支撑」+ 面板顶部「高级」开关打开才显示。正确做法：找不到用默认 0.2 可接受，跳过继续；别为 0.05 的间隙耽误抢来的机时。

## 三、Bambu Studio 预设（重灾区）

9. **外部手写预设注入会被 Bambu 删掉。** 现象：把预设 .json/.info 塞进 `%APPDATA%/BambuStudio/user/<id>/process/`，重启后文件消失、下拉没有。真相：Bambu 启动时清理不认的外来 setting_id/base_id。正确做法：**复用预设只能 UI「保存为预设」**；UI 存的会保留（version 2.6.0.5 那批活着）。别再试外部注入。
10. **Bambu 日志是 .enc 加密，读不了。** 排查预设/切片问题别 grep 日志；靠看 `user/<id>/process/` 文件存留 + UI 表现 + 读盘核对预设 .json 内容。
11. **简中参数名以本地化文件为准，别凭印象。** 查 `安装目录/resources/i18n/zh_cn/BambuStudio.mo`（gettext）。对照：Wall loops=**墙层数**（不是壁圈数/墙体数）、Gyroid=**螺旋体**、Detect thin wall=**检查薄壁**、Top Z distance=**顶部Z距离**、Enable support=**开启支撑**、Part cooling fan=**部件冷却风扇**、Bed temperature=**床温**。写文档/口述参数一律用这些真名。
12. **床温不在工艺预设里。** 真相：床温/首层床温属**耗材**设置，工艺预设存不进。正确做法：每次换盘在耗材里确认床温 65，或把改好床温的耗材也「保存为预设」。
13. **冷却风扇的真名和位置。** "零件冷却风扇"不存在；简中是**部件冷却风扇**，控制前几层的是**起始层风扇**(设0) 和 **满速风扇在**(设第4层)。用工艺下拉旁放大镜搜真名最快。
14. **预设按 层高×机型 分版，别混用。** 0.20H2S 只打 H2S 的 0.20 盘；0.16H2D 只打 H2D 的 0.16 盘。颜色靠**耗材**选，跟工艺预设无关（同一 0.16H2D 预设可打灰 G3p 也可打黑 B1p）。
15. **存完预设立刻读盘核对。** UI 存的可能漏项（例：0.16H2D 漏存稀疏填充图案，还是默认 grid）。读 `user/<id>/process/<名>.json` 逐项对 RUNBOOK 要求，缺的补存。

## 四、炒面（脱板）排查序

16. **炒面=整件脱板被拖成面条。按序查：** ① **悬空处有没有支撑**（P02 中心颈孔悬空，漏开支撑→下垂→喷嘴撞飞整件，最常见）；② **床附着**：Brim 加宽到 10 + 床温 65 + 纹理PEI板洗洁精水洗/IPA 擦（手印=脱模剂）+ 首层速度 25–30 + 前几层关风扇（起始层风扇0/满速风扇在4）；③ 门关好防穿堂风、腔温<40。
17. **大平板+接触面只有一圈环=高翘边风险。** P02"接缝圈朝下"接触面小，附着天生弱；Brim/床温/首层速度三件套必上。仍失败再升级：开**筏层**(代价底面糙)→ 或**翻面**(装配面朝上，牺牲平整度换成功率)。
18. **预览必查两点再点打印**：悬空处下方有树支撑；底面一圈有加宽 Brim。

## 五、样片与数据纪律

19. **轴承配合件等 S1 样片，纯几何件可先打。** P05/P06/P11/P12（6806 座孔/空心轴）务必等 S1 PETG 样片过；P07–P10 支柱/P13 限位/P30/P31 线鞍纯几何可先打。PETG 结论**不跨材料**套用到 PLA。
20. **到货当天先卡尺再重建，别等。** LCD 四孔漏测导致 P23/P24/P25 长期阻塞；屏早就在手边。按 [MEASURE-TODO.md](MEASURE-TODO.md) A 组（中午可测）当天量完回填，解锁面最大。
21. **试打≠放行。** 开打不改变状态：`CANDIDATE_NOT_RELEASED` / `slicer_status=NOT_RUN` / 26 项测试 NOT_RUN / 三个放行布尔 false 保持；未实测不填 PASS。教训集本身也不构成任何放行。

## 六、追加教训（2026-10-15 晚 · 空层警告真凶更正）

22. **"空层无法打印"的真凶是墙层数过多，不是网格坏。** 现象：spacer/P16/P20 报"模型在X和Y之间出现空层"；manifold3d 逐层截面证明几何不空（P20 该层 66mm²）。真相：墙层数6×0.42线宽=2.52mm > 薄特征宽（2.4壁/2mm柱/1.6唇），切片器塞不下6圈→整层丢弃→上半悬空炒面。正确做法：**墙层数=4**（或墙生成器=Arachne+检查薄壁）。曾误判为"环状导出网格坏"并解析重建spacer——重建无害但没治到根；根在切片参数。
23. **几何扫描与切片警告矛盾时，信扫描+查切片参数。** manifold 截面 clean 但切片报空层 → 一定是切片设置（墙圈数/线宽/薄壁开关）问题，别去修网格。

24. **照片定性发现能拦下数字拦不下的设计坑。** 学妹直尺数字全废（±0.5 判不了公差），但一张"焊盘外凸"照片直接判死 P21/P22 压圈和 P01 壁袋（ID14.6 装不进 17–18 宽的模块）。教训：收货先拍**形状特征照**（凸出/侧焊/盖类型/标签），比急着读数值钱；读数交给卡尺，形状交给照片。
25. **湿料是炒面的隐藏主因之一。** 黑卷连犯三次炒面+满床拉丝、灰卷不犯 → 受潮 PLA。设置/朝向/支撑全排除后仍炒面且伴随拉丝=烘料（45–60℃ 4–6h）或换卷，别继续调参数。内部件可先改灰料（RUNBOOK"可灰"）不饿机器。
