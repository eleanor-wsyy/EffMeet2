# firmware/esp32 — ESP32-S3 固件

机内音频、播放、Wi-Fi、转头与状态灯。

## 职责

- 拾音（机内麦克风）+ 音频前处理（AFE）
- 播放（扬声器）+ 独立停止
- Wi-Fi 连接与 PCM 音频流推送
- 单轴转头控制 + 状态灯
- 摄像头 JPEG 抓拍

## 技术栈

- ESP-IDF (C/C++)
- 板卡：ESP32-S3（具体型号待定）
- 音频编解码：板载 Codec（I2S 接口）

## 状态

骨架目录，待实现。当前 Demo 阶段音频走电脑伴侣应用（路线A），固件为最终形态（路线B）的核心。

## 关键约束

- 不承担 FunASR 或通用大模型推理
- 网络发送完成 ≠ 播报完成，需机内播放回执
- 舵机运动不引发复位
