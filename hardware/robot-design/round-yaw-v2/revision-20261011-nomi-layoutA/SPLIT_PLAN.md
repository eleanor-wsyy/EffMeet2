## 1.4 硬件边界（拆分不得违反）

1. **排针上有 GPIO ≠ 可随意分配**——摄像、SPI 触摸、I2S、PSRAM、启动脚、LED 需要一张统一分配表。
2. **BOOT/G0 是启动脚**，按下状态跨复位/上电必须验证；v4 已优先改用**前肩外接轻触键**，不用机械连杆硬推后部板载键。
3. **TP4056 不是 5V 升压，也不自动等于安全边充边用**；Demo 默认外供合规 5V。
4. **屏是 J2 单排 14 针**，SPI 只是商品图推断；**驱动 IC、针序、电压未冻结**。不得沿用微雪的 18PIN 定义。
5. **摄像 FPC 禁止裁剪**；延长须用厂家支持方式。

# 五、拆分铁律（违反即返工）

1. **不做强过盈压装**——轴承座必须分体夹紧/螺接。PLA 偏脆，压装会裂。
2. **不做薄弹性卡扣**——一切靠螺钉 + 圆角 + 受力肋。
3. **不靠材料弹性变形做功能**。
4. **不为好看缩孔、不为省空间折死排线**。
5. **不删功能换外观**：声槽、麦孔、通风、Type-C 口、停止键、状态窗都是真开孔。
6. **不移动实板麦孔去迎合对称装饰**。
7. **不动 `manifest.json` 的 `stage / manufacturing_ready / hardware_validated`**（保持 `false`）。
8. **不生成"伪装成放行件"的 STL**，不把网格改后缀冒充 STEP。
9. **不覆盖旧场景**（`EFFMEET2_PACKAGING_V1` / `R2_*` / `Scene`）。
10. **未实测的项一律标 `unverified`**，不得写 PASS。
