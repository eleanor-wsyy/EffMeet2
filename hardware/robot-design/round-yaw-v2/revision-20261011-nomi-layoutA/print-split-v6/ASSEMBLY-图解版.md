## 先认识它：三个部分

| 部位 | 是什么 | 里面有什么 |
|---|---|---|
| **底座**（下面的大碗） | 不动的部分，稳稳放在桌上 | 两个麦克风、一个小喇叭、一个功放小板、转向用的马达、开关、电线 |
| **脖子**（中间转的） | 让头能左右转 ±45° | 一根空心大轴、两个轴承、齿轮皮带 |
| **头**（上面的球） | 脸和"眼睛" | 屏幕、摄像头、一块核心板（小电脑） |

## 名词小词典（看到不懂的词回来查）

| 手册里写的 | 意思 |
|---|---|
| **P15、P24 这样的编号** | 零件的"身份证号"，对着照片认（见工程手册 §0 图鉴） |
| **M3×8、M2×4** | 螺丝规格：M 后面的数=粗细（毫米），×后面=长度。M3≈一根圆珠笔芯那么粗 |
| **自攻螺丝** | 不用螺母，直接拧进塑料孔里咬住 |
| **顶丝** | 从侧面顶进去的小螺丝，用来锁住转轴不让它打滑 |
| **6806 轴承** | 大号滚珠轴承圈，让头转得顺 |
| **FPC / 排线** | 摄像头那根**黄色软排线**——很脆，禁裁、禁折死 |
| **对角锁 / 对角序** | 像卸汽车轮胎：对角轮流拧，别一口气拧死一颗 |
| **锥面自锁** | 两个斜面压进去自己卡紧，**不用螺丝** |
| **张紧** | 把皮带调紧。留 2mm 余量=还能前后挪 2 毫米 |
| **热熔胶点固** | 胶枪点一小坨固定住 |
| **万用表通断档** | 蜂鸣档：两根表笔碰一起会"嘀"，用来测会不会短路 |
| **判据** | "做到什么程度算合格"的标准，不满足就停下来拍照问人 |

## 阶段 A · 开工前准备（对应工程手册步骤 1–4）

**目标**：东西齐、工具齐、心里有数。

![P01-P07 零件](parts_img/P01.png)

1. **把零件全部摆在桌上**，对着工程手册 §0 的照片一行一行数（照片里有 30 个件）。少件不慌：手册写了缺件时怎么凑合。
2. **把工具凑齐**：内六角扳手（2.0 和 2.5 两个号）、小十字螺丝刀、胶枪、万用表、尺子、两个 5V 充电器＋Type-C 线、9 根细电线、一小盒螺丝螺母。
3. **三个"摸一摸"试配**（全程用手感，**硬压=错**）：
   - 轴承圈套一下大轴和塔座的孔——顺滑或稍紧（紧了拿砂纸轻磨孔）；
   - 舵机自带的白色舵盘放一下齿轮的方槽；
   - 屏幕的 4 个孔对一下黑脸板背面的 4 个柱（间距 77×45）。
4. 如果发现**上盖裂了**或**开关座的小柱断了**——不重打，按手册 §0.6 用胶抢救，继续往下走。

## 阶段 B · 底座里装电子件（步骤 5–10）

**目标**：麦克风、喇叭、马达、开关、供电，全装进大碗里。

5. **装两个麦克风**：小圆板放进胶座里（板上有块凸起的小焊锡头，朝缺口那侧放——放反了盖不上）；翻过来对准胶座底下的圆孔，沿外圈点一圈热熔胶，扣到大碗内壁的声孔上按 10 秒。**左碗一个右碗一个，别装反**。
   ![P32 麦克风胶座](parts_img/P32.png)
6. **装功放小板**：放进托盘，两个孔对两个小柱，M2 小螺丝各一颗轻轻拧住。按线序焊 7 根线（手册 §1.2 有表）；喇叭接"+/-"两个焊孔，**别共地**。
   ![P17 功放托盘](parts_img/P17.png)
7. **装喇叭**：**有纸盆的那面朝外（朝前）**，边上垫一圈橡胶垫，焊片朝后接线。
   ![P16 喇叭托架](parts_img/P16.png)
8. **装马达（重点，容易翻车）**：
   - **先把马达那根三色线从座子尾部的缺口槽里穿下去**（槽约 6.8 毫米宽）——线不穿槽直接放=塞不进去；
   - 马达按进槽里（能轻轻滑动就是对的），两只"耳朵"的孔对座子的孔，用马达自带的小螺丝（M2）穿上，**先别拧死**（后面还要调皮带松紧）；
   - 翻过来从碗底拧一颗 **6 毫米长的 M3 螺丝**固定座子（⚠️ 别用 8 或 10 的长螺丝——螺丝尖会顶到线）。
   ![P15 马达座](parts_img/P15.png)
9. **装停止键**：开关按进小座子，**一定要用胶枪点一坨胶**（它孔浅，不胶会掉）；两根脚焊线接到控制板空闲的脚上。键帽最后再按。
   ![P20 开关座](parts_img/P20.png)
10. **装供电小板**：放进托架用扎带轻轻扎住，口对准碗后面的方窗。（没有这块板的话：电直接从后面引到头部，但**地线要和马达连在一起**。）
    ![P18T 供电托架](parts_img/P18T.png)

## 阶段 C · 装"脖子"传动（步骤 11–19）

**目标**：立起中间的大轴，让头能顺滑地左右转。

![P05/P06/P11](parts_img/P05.png)

11. **立塔座**：四条腿坐到碗底，4 根**长螺丝（55–60 毫米）**从上座的耳朵孔穿下去，碗底各拧一个螺母。先干着装量一下总高约 56 毫米——太长就剪短或垫垫片。
12. **装下面的大轴承**：平着放孔上，**大拇指只压外圈**（压内圈=压坏），感觉"咚"一下到底、和孔口齐平就对了。紧了磨孔，松了缠两圈生料带。
13. **四根小立柱**插在四角（不分方向）。
14. **装上面的大轴承**，盖上上座，4 颗长螺丝**对角轮流**拧到手拧不动，再**加 1/8 圈就停**（拧过头塑料会白掉、以后松）。
15. **插大空心轴**：从上往下穿过两个轴承内圈——顺滑落下=对了。注意**轴上有个削平的面要朝上**，轴承不能坐在削平的位置。
16. **装底部的开口夹环**：掰开套到轴底，合拢，1 颗 M3×10/12 穿上拧紧到"手转有阻力但不卡"。（⚠️ 不要拿顶丝去顶轴——会顶出坑）
17. **装大齿轮（64 齿）** 到轴顶削平处，用 **M2 顶丝**从侧面锁住削平面；小齿轮（32 齿）同理装马达头上（没有就先空着）。
    ![P03 大齿轮](parts_img/P03.png)
18. **装限位摆臂**：在大齿轮**下面同一段削平处**。手转大轴：左右各 45° 顺滑，到 48° 能碰到硬挡。
    ![P13 限位臂](parts_img/P13.png)
19. **皮带**（到了才做）：套上两个齿轮，前后挪马达座把皮带调紧。**没到货就先手转演示，别硬拽马达。**

## 阶段 D · 穿线 + 盖盖子 + 装脖子（步骤 20–22）

**目标**：9 根线穿进大轴，然后按"先盖、后脖子"的顺序合起来。
**铁律（顺序错了会卡死）：线 → 上盖 → 脖子 → 头 → 最后才是脸板。**

20. **穿 9 根线**：每根先套上软护套，从大轴中间的圆孔（22 毫米）穿上去。中间最里面留空别塞线。**这会儿不焊插头**，等穿完了再焊。
21. **盖上盖**：上盖中间的 44 毫米大孔**让线束穿出来**，盖到碗上，突起对准限位臂，4 颗 M3×8/10 对角拧。
22. **装脖管**：线从脖管里穿上去，法兰盘坐在上盖上；管里削平的面对准轴的削平面，M2 顶丝锁住；4 颗 M3×8/10 拧法兰。
    ![P14 脖子](parts_img/P14.png)

## 阶段 E · 装头（可以拿在手里装，步骤 23–28）

**目标**：屏幕、摄像头、小电脑装成"前脸"，最后整体扣进头壳。

23. **小电脑（核心板）竖着插进托架**：排线/充电口那端**朝上**，插到底不晃，2 颗 M3 拧到头壳底部的柱子上。**封头之前先拿充电线插一次试试**——封上就插不到了。
    ![P29 核心板托架](parts_img/P29.png)
24. **装屏幕**：屏幕贴到黑脸板背面，4 个孔对 4 个柱（77×45），后压框盖上，**4 颗 M2.5×16/18 拧到框贴上板就停**——再用力会压碎玻璃。判据：从正面看屏在窗口正中。
25. **装摄像头（重点）**：
    - ① 镜头先对黑脸板中间那个 **6.8 的圆孔**试试——镜头能探进孔里一点就对（这就是"自动找正"）；
    - ② 摄像头那根**黄排线朝下**，先穿过小背板（P33）的槽；
    - ③ 把摄像头小方块推进托架腔里推到底；
    - ④ 盖上小背板（背面的小筋正好压住摄像头），**2 颗 M3×8 自攻螺丝**拧到背板贴住就停（⚠️ 拧过头塑料柱会裂）。
    - 排线**不许剪短、不许折死**，弯的地方留圆弧。
    ![P26 摄像托架](parts_img/P26.png) ![P33 小背板](parts_img/P33.png)
26. **合成"前脸一组"**：黑脸板＋压框＋屏幕＋摄像托架（含摄像头和小背板）先拼成一整组，**先别往头壳里按**。
27. **装隐私滑盖**：导轨（P27）贴到黑脸板**前面**；滑片（P28）**先放进导轨的滑槽里**（从背面敞口放，拨片从窗口穿出来），脸板装上后滑片前后都掉不出来。**是"槽里滑"，不是"盖在上面滑"。**
    ![P27 导轨](parts_img/P27.png) ![P28 滑片](parts_img/P28.png)
28. **键帽**按到开关柄上（松了点一滴胶）。

## 阶段 F · 合体（步骤 29–32）

**目标**：头装上脖子，前脸扣进去，收线。

29. **头壳坐上脖管**：4 颗 M3×8/10 对角拧；线束从轴孔上来、穿过脖管、从头壳底部的大圆孔（40.6）进头，接到核心板上。判据：头坐稳不晃，线没被法兰面压住。
30. **最后压前脸**：把第 26 步那组"前脸"**整个按进头壳前面的方口**——斜面会自己卡紧，**不用螺丝**（⚠️ 别在脸上打孔！）。松了就在边上点三点胶。
31. **上两个线夹**（底座一个、头一个），扎带**绕一圈就行别扎紧**。判据：头转到最左边时，线束还能塞进一根手指。
32. **手动转头 20 个来回**：线不绷不磨、屏幕不出横纹、没异响。

## 阶段 G · 开机（步骤 33–37）

**目标**：先测安全，再通电。

33. **万用表蜂鸣档**：红黑表笔分别碰 5V 和地——**不该响**（响=短路，停下来查）。各信号线对地也扫一遍。
34. **通 5V**：摸一圈不烫没异味 → 看三件事：**屏幕亮、摄像头出图、串口有日志**。
35. **马达小角度动一下**：左右 45° 内不卡、齿轮不跳、不撞挡。
36. **声音测试**：录一段放回来听；说句话喇叭里能播报；**按停止键=播报立刻停**。
37. **拍照留档**。其他 26 项正式测试赛后再说，今天不填表。

## 卡住了怎么办

| 现象 | 先看哪里 |
|---|---|
| 马达放不进座子 | 线穿尾部缺口槽了吗？底板螺丝是不是用长了？（M3×6 才对） |
| 屏不亮 | 第 33 步短路检查做了吗？排线插反了吗？ |
| 摄像头晃 | 小背板（P33）装了吗？两颗螺丝拧了吗？ |
| 转头不顺 | 轴承压到位吗？夹环太紧？线束绷着？ |
| 脸板按不进 | 先别用力——看滑片是不是没先放进槽 |
| 其他 | 翻工程手册 `ASSEMBLY.md` 对应步骤号（两边编号一致），或拍照问人 |
