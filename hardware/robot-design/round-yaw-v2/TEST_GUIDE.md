# EffMeet2 圆润转头版 · 测试指南

更新：2026-10-10（北京时间）。与[安装指南](ASSEMBLY_GUIDE.md)、[当前BOM](BOM.md#final-purchase-decision)、[打印方案](PRINT_PLAN.md)配套。**本指南定义待执行测试，不是测试报告。** 当前固件与可打印机构尚未完整落实，未做的测试必须记录为NOT_RUN或BLOCKED；本次文档不升级硬件/制造状态。

## NOMI方向的同步复测

外观改为球头/圆黑面板和内藏短颈后，按[组装接口更新第6节](EXTERIOR_ASSEMBLY_REVISION.md#6-对测试指南的增量要求)复测T04、T05/T06、T12/T14/T15、T07/T08/T17及T24：真矩形屏无遮挡、滑盖有效、内藏边不擦盖/夹线、声孔与装壳表现不退化。26项ID和判定逻辑不变，旧外观测试不能自动沿用。

## 1. 时间有限时按这条顺序

1. **供电前**：T01/T02，确认资料、极性、接线与结构。
2. **裸板/独立模块**：T03–T11；缺固件或对应驱动就停在该项，不装壳掩盖问题。
3. **机构与跨轴线**：T12–T16，先手动/低速/小角度，再三个目标角与50循环。
4. **入壳与整机**：T17–T24，包含授权提醒、实体停止、故障恢复与30分钟运行。
5. **产品音频与交接**：T25/T26。AEC未完成可以注明“仅初样演示”，不能标为完整产品验收。

声卡示例能跑、屏亮、模型能转、网页mock显示completed分别只是局部证据，不自动使整机测试通过。用电脑麦/电脑扬声器完成的路线A软件演示不能填为机内双麦/扬声器通过。

## 2. 统一测试设置

- 给样机编号，记录主板/屏/相机/舵机/轴承实物版本、接线表版本、CAD与打印料/层高、固件来源与提交、软件提交。无真实固件就写“未实现”，不要填README日期冒充版本。
- 台架位于稳定桌面，运动不靠近人手。能随时切断舵机供电；软件停止按钮目前只定义停止播报，不能假设能急停运动。
- 初次带载动作先小角度低速；出现顶挡、跳齿、磨线、冒烟/焦味、异常发热、持续抖动或失控，停止测试、断电排查。不要为了凑50循环强行重复故障。
- 摄像/录音默认用合成文字卡、测试语音或已同意的参与者；原始人声/人像、SSID、凭据、令牌和日志敏感信息不要上传公开仓库。
- 记录角度的是**实际头部**，不是只看舵机PWM。保持供电、桌面、距离与音量一致再比较裸板/入壳、保持/转动。

### 首轮暂定阈值

下表来自本版BOM的样机目标，并补充可执行记录方法；团队可在实物选型后冻结，但不得测试失败后无记录地放宽标准来伪造通过。

| 项目 | 首轮目标 | 记录方法／边界 |
|---|---|---|
| 头角 | 左45°／正向0°／右45°，误差≤3° | 顶视刻度/量角器，记录实角；这是拟定目标，非舵机出厂精度 |
| 转向 | 约1–2s完成一次目标转向 | 视频计时；不靠增速硬顶或用标称空载速度代替 |
| 停止播报 | 暂定≤1s，5次均实际停止 | 播放音频/录像与按钮事件对齐；只测播报，不暗示硬件断麦/运动急停 |
| 重复转向 | 50循环，1循环=左45°→0→右45°→0 | 记录循环数与各故障；是首轮联调，不是寿命测试 |
| 组合运行 | 30min | 定义本轮负载/环境/音量，记录故障、供电和温度；不是长时可靠性认证 |
| 听辨 | 同一约1m位置听5句固定语音 | 写原句、听辨情况和杂响；不自动证明ASR准确率/会议室覆盖 |
| 裸打外观 | 允许均匀细层纹，不接受大支撑疤/毛刺/裂纹/翘边 | 同光照照片＋手感/装配检查；不是注塑质感 |

温度、供电、峰值电流、动态线缆寿命等取各实际器件/线材的允许范围和实测数据；没有根据不编造数值。

## 4. 状态怎么填

- **NOT_RUN**：有方案，但尚未执行。模板默认全部此状态。
- **BLOCKED**：缺实物、固件、接线、CAD或其他前置条件；写阻塞原因和下一步。
- **FAIL**：已执行但不满足目标，保留失败证据、修复动作和复测。
- **PASS**：实际执行且符合该项条件，注明版本/结果/证据；不是根据文档或模拟推断。
- **N/A**：本轮经确认不适用，只用于确实无此功能的条件件；必需测试不能用N/A消除。未做AEC是BLOCKED，不是N/A。

“整体通过”至少要求本轮定义的全部必需项实际PASS；初样只有部分测试通过时，对外只报告范围，例如“已通过显示/摄像/三姿态，AEC和业务回执仍BLOCKED”。不得把NOT_RUN、BLOCKED或FAIL改成绿色状态以形成完整演示。

## 5. 最少记录和文件

复制[TEST_RECORD_TEMPLATE.csv](TEST_RECORD_TEMPLATE.csv)到同目录local-only/test-records，命名为TEST_RECORD_样机编号_日期.csv后填写；保留原模板的NOT_RUN状态不改。一行对应一个测试ID，保留26项；重复修复需要多次记录时复制该行并递增attempt，不覆盖失败历史。CSV没有公式，可直接用表格软件打开。

表头包含：样机/版本、执行人和时间、前置/实际结果、状态、证据位置、问题、修复与重测。证据可以是本地受控目录路径或已脱敏的公开记录，模板不含真实隐私数据。不要只写“OK”，要能定位“哪版、哪步骤、看到了什么”。

| -45° | 待实测 | 待实测 | 待实测 | NOT_RUN |
| 0° | 待实测 | 待实测 | 待实测 | NOT_RUN |

## 6. 常见问题先排哪里

| 现象 | 先停止/检查 | 不要采取的捷径 |
|---|---|---|
| 转头时主板复位 | 停舵机；查独立供电/共地、板端压降、日志与线接触 | 增加电压或把两路5V正极并联 |
| 屏花/相机断帧 | 断电查接口方向/锁扣；短线基线与跨轴线对比 | 拔插带电FPC、盲加长或只凭同针数换线 |
| 舵机保持啸叫/抖动 | 解除负载安全排查；供电、齿隙/带张紧、标定与机械卡滞 | 用泡棉封死壳体掩盖噪声；把金属齿当静音保证 |
| 头壳动但底座也转/滑 | 停动作；查固定架、脚垫、重心、线束拉扯 | 先塞未固定配重或提高驱动力硬转 |
| 录音差/播放回声 | 对比裸板/入壳声孔、密封、参考与真实AFE配置 | 用电脑麦替代却写硬件通过，或将暂停采集当AEC |
| 按键盖上后失效 | 断电检查帽/开口行程、是否常压与输入日志 | 强压盖板、把按钮直接接未知GPIO |
| 透光/屏窗不清楚 | 查框是否压/挡有效区、屏自身亮度与表面保护状态 | 临时加不透明黑板或把打印透明件当光学玻璃 |
| 整机未完成但演示赶时间 | 明确只演示已验证范围，保留BLOCKED项 | 让fake/mock回执冒充机内播报/转头完成 |
