# 圆润转头版 · 最少操作打印与装配方案

更新：2026-10-10（北京时间）。按用户“能打印则打印，少点操作、时间有限”的最新反馈修订。与[BOM第12节](BOM.md#final-purchase-decision)配套；本文件是工艺决策，**不是已经存在的可打印文件或制造放行单**。

## 外观接口最新补充

按用户要求靠近NOMI球头/圆黑脸，并保持本文件的硬件/少工序路线不变。黑面罩框收敛为近圆黑色打印面板，中央仍开普通矩形LCD窗；头壳接收面、相机/滑盖支架、短颈内藏边与支撑朝向须重核。具体分件与装入顺序见[外观/组装同步说明](EXTERIOR_ASSEMBLY_REVISION.md)。这是待CAD落实的接口更新，不是制造放行。

## 1. 本轮只走这条路线

**A1＋现有PETG做关键配合验证 → 学校H2S＋白/黑ABS-GF正式件 → 去支撑/去毛刺 → 用螺钉装配。**

不打磨补土、不喷漆、不做退火、不切亚克力屏窗、不订机加工轮毂。打印件尽量同材；两颜色分批，不做一件多色反复换料。第一轮看样片接受裸打哑光后继续。

“贵的材料”落在有厂商资料和机器配置的工程级ABS-GF，不等于越贵越好。它有哑光外观及玻纤增强，也较脆，不用薄弹性卡扣；采用螺钉、圆角和受力肋。PC＋专业喷涂是上一轮草案，已因工序多取消；PAHT-CF/PPA-CF不作为首轮必买。官方材料/喷嘴/干燥信息见BOM的S15/S16，打印前由实验室管理员确认对应配置与库存。

## 3. CAD上机前最少必须补的内容

这些是避免废壳的必要工作，不因工序少而省略：

1. **实物尺寸锁定**：板卡装配高度/插头、屏和相机、舵机固定耳/舵盘、轴承尺寸和轴肩。新轴承路线是两只6806尺寸级件，不可直接复用旧56×18占位的“通过”结论。
2. **功能开孔**：扬声器真实贯通出声孔、两个板载麦声孔及通道、显示窗口、摄像孔/滑盖、按钮、LED、USB与电源线出口。不能打印一个听觉封闭的大壳。
3. **安装/受力**：板柱、轴承座、舵机架、头部接收面、连接盘、螺钉孔、软/硬限位、FPC路径。可采用可更换小支架，减少大壳重打。
4. **厚度与公差**：保留外壳名义2.4mm起点，受力区局部加肋；底板提出3.2mm设计起点，须重新算与主板的余量。所有新厚度是CAD待执行方案，未改parameters.json或现有模型。
5. **导出白名单**：只导出已完成结构的零件；排除MAINBOARD/LCD/CAMERA/SERVO/BEARING/SPEAKER代理、KEEP_OUT与布尔控制。闭合网格、孔、支撑可取性和装配需一起检查。

### HANDOFF中需要纠正的旧推论

- bottom_z=2是Z坐标，不是厚度；现有脚本底板从z2到z4.4，名义厚度约2.4mm。是否翘边取决于材料、形状、粘附和工艺，不能只据Z坐标认定“严重翘边”。
- 头壳已经有评估网格闭合/非流形检查，但还缺打印壁厚、自交、安装和全件装配放行；“草模不是可打印成品”不等于从未形成闭合体。
- 上盖与底座外包络关联，不能凭HANDOFF中的约152×152把它当已核实导出尺寸。
- H2S单喷嘴也能在合适AMS配置下换料；不是绝对“不能用界面支撑”。本轮为省材料/换料时间选择同材支撑，不安排特殊支撑料；是否支持某界面料仍须核官方兼容性。
- 自动孔径补偿有材料/配置条件，也不能代替配合样片；0.2mm喷嘴与玻纤料不适配，不为细节盲目换小喷嘴。
- 不用缩比样件验收安装孔；配合孔/轴承座/滑槽必须1:1。

## 4. 最少打样顺序

**第一步：A1，现有PETG，1:1关键小件。** 打轴承座/轴肩短样、舵盘适配件、滑盖/按钮配合片、板柱位置模板。先验证实际尺寸和装入顺序。时间紧时不要求A1先打完整四件大壳；小件不能证明全壳能装时才补局部或大件。

**第二步：H2S，正式ABS-GF，合并一盘关键小件＋一个曲面样片。** 这一步验证正式料的收缩/孔径、表面、支撑界面和细节；PETG试片不能代替ABS-GF配合。尺寸合格、裸打外观接受后再打大壳。

**第三步：H2S，白料大壳与黑料小件分批。** 头壳、底座、上盖各自整件，不把整个机器人封成不可拆的一件。不在每层反复白黑换色。只进行去支撑、切毛丝/去毛刺、螺接安装。

**第四步：联装检查。** 左45°/正向/右45°、连续50次转向，观察不夹线/断屏/断帧/复位；再做30分钟组合运行、停止按钮、隐私遮挡和音频检查。这些是首轮目标，不是已通过结果或寿命认证。

## 5. H2S切片起点

以下数值为首轮样片起点，不能未经切片/实验室确认直接用于无人值守打印。优先官方“Bambu ABS-GF @ H2S”模板，不跨用A1配置。

| 设置 | 本轮决定 |
|---|---|
| 材料/颜色 | Bambu ABS-GF白41100、黑41101；不要以同名普通ABS替换却仍沿用验证结果 |
| 喷嘴 | 合适0.4mm硬化喷嘴，适合本轮孔/轮齿细节；厂商更推荐0.6，若0.4样片堵塞/不稳定就换0.6并重测配合 |
| 层高 | 外观曲面0.16mm起点；隐藏支架可0.20mm；先看支撑痕和细节，不靠极小层高增加大幅耗时 |
| 外墙与受力区 | 4–6墙为切片起点；实际壳厚和局部肋由CAD决定，不机械堆高填充率 |
| 干燥/存储 | ABS-GF官方80℃/8h，打印后密封干燥；实验室设备按管理员安全要求使用 |
| 温度/腔体 | 使用具体耗材官方H2S模板与封箱；官方材料页给出的热端240–270℃、床80–100℃作为核对范围，不把最高腔温当必须设置 |
| 头壳朝向 | 优先面罩安装环朝床面，使支撑从前开口可取、接触痕在内侧/框遮边；必须先切片检查薄口边、底部截口与内悬垂 |
| 底座 | 已有平底区域朝下，杯口朝上；需要时Brim，保持平台清洁和官方适配粘附方式 |
| 上盖/框/支架 | 把支撑接触与接缝放隐藏面；不能为免支撑牺牲承力层方向 |
| 支撑 | 同材、必要处才启用、切片确认能拆出；不为“不用后处理”放任大悬垂 |
| 订单重量/时间 | 由最终导出件切片给出；现在没有可打印件，不能编造总克数或承诺“一下午一定完成” |

无需同时购买0.2/0.4/0.6多套喷嘴；先问学校0.4硬化现有配置和ABS-GF库存。打印时不关闭通风去追腔温，也不把PC/ABS材料换到无合适封箱的A1。

## 6. 质感目标与舍弃项

接受：均匀细层纹、玻纤哑光质感、白色材料本色与黑色框；正常组装缝可见但整齐。

不接受：大支撑疤、拉丝、缺层、翘边、脆裂、毛刺扎手、装配需强砸、动作卡住。若样片不合格，优先调整朝向/支撑/参数/可更换小件，而不是默认增加全壳喷漆。

不承诺：裸打等于注塑光面、整片黑玻璃面罩、NOMI运动噪声或未经测试的平替长期寿命。若用户仍要求这些效果，必须接受相应工序或驱动成本，与本轮少操作目标另做取舍。
