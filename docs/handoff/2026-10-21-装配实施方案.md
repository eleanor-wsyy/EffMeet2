# 2026-10-21 装配实施方案（今晚执行版）

> 目标：今晚完成整机装配与上电，验收线 = 能转头、能拾音、能出声、停止键有效、屏能亮。
> 本页是执行摘要；逐步操作看 [装机图解版](../../hardware/robot-design/round-yaw-v2/revision-20261011-nomi-layoutA/print-split-v6/ASSEMBLY-图解版.md)（37 步）或 [工程手册](../../hardware/robot-design/round-yaw-v2/revision-20261011-nomi-layoutA/print-split-v6/ASSEMBLY.md)。

## 1. 跨轴 = 11 根（保留已验证固件：麦/功放各一对 I2S）

| # | 线 | 底座端 | 头部端（核心板） |
|---|---|---|---|
| 1 | 5V | 供电入口＋功放 VIN | 5V |
| 2 | GND | 底座全部共地 | GND |
| 3 | 3V3 | 两只麦 VDD | 3V3 |
| 4 | MIC BCLK | 两只麦 SCK（并线） | GPIO4 |
| 5 | MIC WS | 两只麦 WS（并线） | GPIO5 |
| 6 | MIC SD | 两只麦 SD（并线，L/R 分左右槽） | GPIO6 |
| 7 | AMP BCLK | 功放 BCLK | GPIO15 |
| 8 | AMP WS | 功放 LRC | GPIO16 |
| 9 | AMP DIN | 功放 DIN | GPIO17 |
| 10 | SERVO PWM | 舵机橙线 | GPIO38 |
| 11 | KEY | 停止键（另一脚接地） | 空闲非启动 GPIO |

功放 **SD 在模块端接 VIN（5V）常开，不跨轴**；GPIO18/EN 悬空。

## 2. 连接方式：全杜邦，唯一焊点 = 喇叭

| 连接点 | 做法 | 焊点 |
|---|---|---|
| 两只 INMP441 | **P32 照用**：模块本体入腔，排针**朝碗内**（凸出允许、不顶杯壁）；杜邦插针；L/R 跳线分接 3V3/GND | 0 |
| MAX98357A | 5 根杜邦母对母＋**SD→VIN 短跳线**；GAIN 悬空 | 0 |
| **喇叭** | 两个焊片各焊 1 根到功放 +/−（功放端若为焊盘再 +2；螺钉端子则免） | **2–4** |
| 停止键 | 杜邦母头直插 4 脚，插后热熔胶点固 | 0 |
| 屏（ILI9341 2.8″） | 杜邦：VCC→3V3、GND、CS→G10、RST→G14、DC→G9、SDI→G11、SCK→G12、LED→G47；触摸/MISO 先空 | 0 |
| 摄像头 | 板载 FPC 座直插 | 0 |
| 舵机 | 1 根公对母（公头插舵机母座） | 0 |
| 供电 | 成品 **USB-C 5V 转接线**从后窗引入；E17 小板不装 | 0 |
| 头端 11 根 | 杜邦母头直插核心板排针 | 0 |

## 3. 今晚执行顺序

1. **电装（底座）**：麦装 P32（杜邦）→ 功放入 P17（杜邦＋SD 跳线）→ 喇叭入 P16（焊/夹）→ 舵机入 P15（线先穿尾槽）→ 按键入 P20（杜邦＋胶）→ USB-C 供电线进后窗。
2. **桌面先测**（按 [wiring-bench](../../hardware/electronics/wiring-bench.md)）：`mic` / `tone 880 500` / `servo 0` / `led idle`，确认不虚接。
3. **传动**：阶段 C 先选 **P03 决策门**（[§2-7](../../hardware/robot-design/round-yaw-v2/revision-20261011-nomi-layoutA/print-split-v6/ASSEMBLY.md)）：路径 1 手工扩孔 Ø35＋开口衬套；路径 2 对开 A/B 半（`p03_fix/`）。单元：碗底螺母→塔座→柱→P06→长螺丝最后从上穿。
4. **穿轴合体**：第 20 步穿 11 根杜邦（逐个过 Ø22）→ P02 → P14 → 头。
5. **屏点亮**：烧 `083c164` 起的固件，开机自动七色彩条；REPL `lcd` / `lcd fill r g b` / `lcd off|on`。
6. **装壳收线**：前脸组（P24/P25/LCD/P26/P33/P27/P28）压入 P23；P30/P31 线夹不扎紧；转头 20 次复查。
