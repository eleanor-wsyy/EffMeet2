# EffMeet2 席位牌 · 封装布局 v1

日期：2026-10-10。选用现有01「桌面席位牌」作为外观主线，先把真实开发板与其余器件的安装空间落实。

## 交付范围

这是**原生可编辑的Blender三维占位模型**，不是把AI效果图转成一个假3D文件。它用于确认尺寸、前后层次、器件预留与整体比例，处于可逆Blockout阶段。

**尚未完成可制造结构，不可直接作为打印订单：**安装柱、真实孔位、盖板固定、轴承/舵盘连接、相机滑槽、声学通道、线束固定、热设计和打印公差仍待实物核对。没有导出“可打印STL”或生产STEP，以免误用。

## 文件

- `EffMeet2_席位牌_封装布局_v1_审阅.blend`：建议打开的中性建模审阅版本；修正壳体/盖板截面，器件位置与尺寸不变。
- `EffMeet2_席位牌_封装布局_v1.blend`：初始原生布局文件，保留为检查点。
- `parameters.json`：毫米制统一尺寸、占位、坐标与证据状态。
- `fit-report.json`：预留体积与腔体、同舱器件之间的空间检查。
- `yaw-rigid-clearance.json`：±45°时的刚性壳体与底座高度间隙，不验证线束、扭矩或实际舵机行程。
- `production/validation_report.json`：该占位范围内的求值网格拓扑与封装检查；不是生产放行证明。
- `production/blender_geometry_audit.json`：套件附加审计，完整保留未知项，不把未做的检查伪装成PASS。
- `renders/review-06/`：装配、正视、侧视、去壳布局、侧向布局和顶视图片。早期曝光图片保留在上一级。
- `build_packaging.py`：构建脚本；`render_review02.py`：原生模型审阅脚本。

新版采购清单位于仓库`hardware/robot-design/archive/seat-card-v1/BOM.md`，与本文件使用同一组尺寸和假设。

## 如何看模型

使用Blender 5.2或兼容版本打开审阅文件，选择场景`EFFMEET2_PACKAGING_V1`。

- `HEAD_SHELL` / `HEAD_BACK` / `FACE_MASK`：头部壳体、后盖和面板的可逆几何控制。
- `BASE_SHELL` / `BASE_LID`：底座与盖板。
- `MAINBOARD_BODY`、`LCD_BODY`、`CAMERA_BODY`、`SERVO_BODY`、`SPEAKER_BODY`：器件占位，不是精细元件CAD。
- `CUTTERS_AND_KEEP_OUTS`集合：保留腔体、开口和器件预留盒；可取消隐藏检查，不建议直接删除。
- `HEAD_YAW_CONTROL`自定义属性`yaw_deg`：-45到45度预览。该范围只用于模型检查，不能复制为已经验证的固件参数。

技术预览中的绿色表示主板、蓝色表示LCD、黄色表示摄像头、深蓝表示舵机、灰色圆柱表示扬声器。这些是诊断配色，不是最终CMF。去壳视图会隐藏固定支架，因此看起来悬空；不得把这类图片称为真实装配爆炸图。

## 空间结果与边界

五个器件的当前保守预留盒均位于对应腔体内；同舱器件预留盒互不相交。主板与LCD前后预留间隔约23mm；LCD与摄像头横向间隔约5.3mm；舵机与扬声器前后间隔约26.5mm。

最小0.6mm是底座器件**预留盒之外**到内底面的额外余量，不是装配公差。外壳能否真实装下仍取决于实物总厚、插头/排线、支架和声学通道；不能仅凭这些数字下单外壳。
