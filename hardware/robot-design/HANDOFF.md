## 2026-10-11补充：主板选型变更（Korvo-2 → 微雪）

> **本节为 2026-10-11 新决策，已由组长确认。** 它使 [BOM 第 11 节](round-yaw-v2/BOM.md) 的"低成本替代路线"由**未采纳提案**转为**执行路线**，并覆盖第 3 节 E01/E02/E03 的既有采购状态。

### 变更内容

| 原 ID | 原选型 | 现选型 | 变化 |
|---|---|---|---|
| **E01** | Korvo-2 V3.1（≈¥700 含 E02） | **微雪 ESP32-S3-CAM-OV3660**（≈¥180） | 换板 |
| **E02** | 乐鑫 LCD 扩展板＋2.4″ 屏套装 | **删除**，改微雪 18PIN FPC 屏模块 | 屏 2.4″→2.0″/2.8″ |
| **E03** | 单独采购 OV2640 | 由**板载 OV3660** 替代（硬件 JPEG，优于 OV2640） | 删除采购项 |
| **E04/E05** | 跨轴 LCD FPC + 摄像头延长 | 采用**布局 B** 时**可删除** | 见下 |
| **E07/E08** | Micro-USB 数据/供电线 | 改 **Type-C 线**（微雪为 Type-C） | 线材更换 |
| **E13** | 舵机 PWM 驱动板（PCA9685 备选） | **删除**，改用 ESP32-S3 **LEDC/RMT 直接出 PWM** | 简化 |

### 为什么现在可以换

1. **固件未绑定板卡。** `firmware/esp32/README.md` 原文写明「板卡：ESP32-S3（**具体型号待定**）」且「**骨架目录，待实现**」——没有现存固件需要改写。
2. **服务端零引脚依赖。** `services/relay/*.py` 对 `korvo / es7210 / es8311 / GPIO / pin / i2s / servo / pwm` 检索**零命中**。
3. **音频芯片组完全相同。** 微雪与 Korvo 同为 **ES7210（ADC）/ ES8311（Codec）/ NS4150B（功放）**，同为双麦阵列——接法可迁移，不是从零开始。
4. **切换成本尚未固化。** 面罩 C02 开口未定稿、壳体未打印、固件是骨架——**这是切换成本最低的时刻**，壳体一旦打印即锁死。
5. **路线 A 不依赖板载 AEC。** 见上节。

### 连带收益

- **物流瓶颈解除**：微雪为深圳厂商，京东现货次日达；原 Korvo 为境外代理链路，2–5 天且是当时全链最长的一段。
- **第二个卡点同时解开**：采用**布局 B（整板进头部）**时可删除 E04/E05 跨轴 FPC——那是第二批才敢买的定长件。
- 微雪板带 **3.7V 锂电充放电路**，演示可脱离电源，对拍摄演示视频有直接价值。

### CAD 可打印化的实际缺口（给建模接手人）

当前 `build_round_yaw.py` 生成的是参数化草模。经阅读该脚本，现状如下：

**几何基础（可复用）**
- `BASE_CUP` / `BASE_LID`：单一径向剖面 + 原生 Screw 360°，剖面为闭合轮廓，`use_merge_vertices` 已开，旋转后为闭合实体；
- `HEAD_SHELL`：Sphere − 内球 − 底面 − 面罩开口，Boolean solver 已为 `MANIFOLD`。

**必须解决（否则打不出/装不上）**
1. **无实体化与真实壁厚**：头壳壁厚目前只是内外球半径差（约 2.4 mm 的数值差），导出前须确认为**闭合单流形实体**，而不是两层面片；Boolean 结果需检查非流形边与自交。
2. **底座底厚仅 2 mm**（`bottom_z=2`）：直径 164 mm 的 2 mm 底会严重翘边，须加厚或加肋。
3. **无安装结构**：`parameters.json` 的 `unverified` 第 5 条（bearing SKU / motor mount / transmission ratio / head receiver / hard stop）全部未定，因此**轴承座、安装柱、连接盘、卡扣、螺钉孔、分件口无法定尺寸**；这些是 S2 阶段的阻塞项。
4. **无功能开孔**：出声孔是 `SPEAKER_PORT_POSITION` 位置代理、无真实穿孔；**麦克风孔不存在**；面罩/屏窗、摄像孔、按钮孔均未完成。当前壳体打出来是**听觉全封闭**的。
5. **代理件必须排除**：所有器件 proxy（MAINBOARD/LCD/CAMERA/SERVO/BEARING/SPEAKER）与 `KEEP_OUT_*` 线框盒**不得进入导出网格**（KEEP_OUT 为 `hide_render` wire，误导出会变成实心块）。
6. **打印公差未定**：`unverified` 第 8 条（thermal, tipping stability, print tolerances and fasteners）未定，孔的公差与收缩补偿无法冻结。

**建议的分阶段做法**（避坑）
- **先做 S1+S3**：实体化 + 真实壁厚 + 补功能开孔（出声孔、麦克风孔、按钮孔、屏窗开口），产出一个**"能打、能装、能出声"的验证壳**；
- **S2（安装结构）等轴承/舵机/传动选型锁定后再补**，否则会把猜测尺寸固化进打印件，打完即废；
- **S4**：分件（头壳单体、底座杯体、上盖、短颈）、收缩补偿、导出 STL/STEP。
