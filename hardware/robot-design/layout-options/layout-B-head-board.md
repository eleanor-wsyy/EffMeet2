## 3. 验收要点（本方案特有）

| 项 | 通过标准 | 说明 |
|---|---|---|
| **头部重量/惯量** | 装整头后 SG90 仍能 1–2s 转向、头角误差 ≤3°、无明显啸叫抖动影响会议 | **本方案第一验收项**；不达标即判不通过 |
| 转动连续 50 次 | 无断屏/断帧/复位/夹线 | |
| **麦克风拾音** | **头部双麦随头转**——转头时拾音特性变化须实测并写入说明 | ⚠️ **C06 必须改写**；不得宣称"转头实现指向性拾音" |
| 温升 | 30 分钟组合运行记录板端压降与头部温升 | 被动散热不够即须改结构 |
| AEC | 重测（换板 + 麦位变化） | **比 A 更需要重测**；初赛不阻塞，决赛 11.5 前必须 |
