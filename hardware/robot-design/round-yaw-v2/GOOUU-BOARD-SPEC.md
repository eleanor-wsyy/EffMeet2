> **⚠️ 2026-10-13 v6/A2 口径更新（优先于下文 v4 内容）：** 核心板装在**头部**（旧"板在底座"作废）；**电池/TP4056 推迟到路线B/决赛，本轮不装、不买**；**扩展板实测 95×87×12 放不下，v6 不装**；底座内腔与整机按 v6/A2 重建（153×139.4×200.8）。下文 §4.5/§5/§6 的扩展板与电池讨论仅作历史。

## 0. 一句话结论

**买得到、明天到、尺寸已知（62.6×28.3mm），但没有板载音频**——麦克风/功放/电池管理要靠外接模块补。
选它的唯一理由是**交付速度**：微雪那块省事得多（板载双麦 + 音频编解码），但国内拿货要等。

## 3. 引脚（全部 GPIO 引出到 2.54mm 排针）

| 位置 | 引脚 |
|---|---|
| 左列（上→下） | `3V3` `G4` `G5` `G6` `G7` `G15` `G16` `G17` `G18` `G3` `G46` `G9` `G10` `G11` `G12` `G13` `G14` |
| 右列（上→下） | `3V3` `G43` `G44` `G1` `G2` `G42` `G41` `G40` `G39` `G38` `G37` `G36` `G35` `G0` `G45` `G48` `G47` `G21` `G19` `G20` |
| 底部 | `5V` `RST` `BOOT` `GND` + USB |

**关键**：`G10–G14` 都在排针上 → **I2S 可以用**（外接麦克风与功放）。
`G0` 是 BOOT 键，可复用为停止键。

## 4. 板载有什么 / 没有什么

| 有 | 没有（必须外接） |
|---|---|
| ESP32-S3-**N16R8**（16MB Flash + 8MB PSRAM） | ❌ **麦克风** |
| 摄像头 FPC 座（OV2640/OV3660/OV5640 可选） | ❌ **音频编解码（ES8311/ES7210）** |
| **USB Type-C**（+ 另一 USB 口） | ❌ **功放（NS4150B）** |
| TF 卡槽 | ❌ **喇叭接口** |
| **W2812B RGB 灯** | ❌ **电池充放管理** |
| 0.96″ OLED 座 | ❌ 18PIN LCD 专用座（屏经排针接） |
| 45 GPIO / SPI / **I2S** / I2C / PWM / RMT / ADC / UART | |

**⚠️ 对方案的影响**：「可核对的会后记录」依赖麦克风拾音，本板无麦 → 必须外接，**这是选它付出的代价**。

## 4.5 套装里额外含「扩展板」——体积要留意（历史讨论；v6 结论：不装）

商品实拍显示：核心板插在**扩展板**上，扩展板带屏幕座、Type-C、蓝色接线端子、排针，2.8″ TFT 直接插上即可运行。

**v6 结论（2026-10-13）：扩展板实测 95×87×12，放不下，不装。** 以下决策点仅作历史：
- ~~用扩展板：省接线、有屏幕座，但整体体积大，底座内腔 180×164×76 塞不塞得下要算~~（旧 v4 内腔；v6/A2 已重建为整机 153×139.4×200.8）
- 不用扩展板：核心板直接排线接屏与模块 ← **v6 采用这条**

## 5. 外接件（v6 实配：麦＋功放；电池/TP4056 推迟）

| 件 | 型号 | 数量 | 作用 | 参考价 |
|---|---|---|---|---|
| I2S 麦克风 | **INMP441** | **2** | 双麦拾音（替代板载麦阵列） | ¥8–15/个 |
| I2S 功放 | **MAX98357A** | 1 | 接喇叭播放提醒 | ¥8–12 |
| 锂电充电／保护 | **TP4056**（带保护） | **0（推迟）** | v6 不装；路线B/决赛再议 | — |

**代价（如实记录）**：
- 多 3 类模块 + 接线，比微雪方案麻烦
- **AEC 更难**：无硬件回声参考通路，只能软件兜底
- 双麦阵列要自己搭，声学通道自己设计
- **C06 麦孔不再按整板开**，改为按 **INMP441 模块**安装位开

## 6. 对建模的直接结论

| 项 | 结论 |
|---|---|
| **板体尺寸** | ✅ **62.6 × 28.3 mm**，可立即开腔体 |
| 摄像头 | 经 FPC 外接，**镜头位置由实际安装方式定**，到货实测 |
| 麦克风 | 装 **INMP441 ×2**，固定在**底座**（不随头转；v6 布局A2：麦/功放/喇叭/舵机/按键都在底座） |
| 喇叭 | MAX98357 → 扬声器，底座前部声槽不变 |
| 电池 | **不装**（v6 外供 5V≥2A；TP4056＋锂电推迟到路线B/决赛） |
| 屏 | **2.8″ TFT 带触摸（随套装）**：面板丝印 `HSD028309 A6`；**单排 14 针 J2 连接器** → 判定为 **SPI**（高置信度，非规格书）；标准分配 VCC/GND/CS/RESET/DC/MOSI/SCK/BL/MISO + 触摸 5 线 |
| 停止键 | 复用板载 `BOOT(G0)` 或另接轻触开关 |
| 舵机 PWM | 核空闲可输出GPIO及启动／摄像／屏／音频占用后用LEDC/RMT |
