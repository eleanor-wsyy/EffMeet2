## 1. 机器现状（沿用 v5 手册查证）

| | 内容 |

## 2. 全局切片设置（所有盘通用）

| 项 | Bambu Studio 默认 | 改成 | 理由 |
|---|---|---|---|
| 墙层数 | 2 | **6** | 名义壁厚 2.4mm÷0.4 喷嘴＝6，壁才实心不透光 |
| 稀疏填充 | Grid 15% | **Gyroid 15%** | Grid 交叉点重复挤出，大件刮擦 |
| 支撑 | 关 | **开＋树状**，外墙 2，顶面 Z 0.25–0.3 | 树状好拆、痕浅 |
| Brim | 自动 | 仅外侧 / 5mm（大件） | 防翘边 |
| 热床 | 官方 | 60–65℃ | 防翘 |
| 首层层高 | 0.2 | 不动 | 厚首层粘得牢 |
| 接缝 | 随机 | **对齐** | 别满壳麻点 |
| 腔温（H2） | 自动 | **盯 <40℃**，广州室温高要盯 | PLA 热变形约 55℃ |
| 喷嘴温度/速度/风扇 | 官方 PLA Matte | 不动 | |

## 3. 打印顺序（先样片后整件）

1. **S1 样片（PETG @A1）**：轴承座孔／空心轴配合、带轮齿槽×188 带、舵机耳孔、屏四孔、面板四柱 —— 结果回填 [MEASUREMENTS.csv](MEASUREMENTS.csv)，未实测不填 PASS。
2. **S2 正式料样片（PLA Matte）**：同接口复测收缩/孔径/表面。
3. 样片过了再排 G1–G3、B1–B3。
4. 样片是**正式料的另一次打印**，PETG 结论不跨材料套用到 PLA。
