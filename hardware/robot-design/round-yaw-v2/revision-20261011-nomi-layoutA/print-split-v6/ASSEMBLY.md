## 装机总流程（从零开始 · 连续步骤 1–37，照着做就行）

> 上表是概览；**下面这条主线才是逐步操作**。每步：做什么 → 判据（不满足就停、拍照）→ 用料。细节展开见对应节。
> 铁律（全程）：**线 → P02 → P14 → 头 → 最后 P24**；FPC 禁裁禁折死；轴承不敲不磨；螺钉对角、贴合即停 +1/8 圈。

### 阶段 A · 准备（§0 / §0.5）

1. **清点零件**：按 §0 图鉴逐行对桌上的件（✅ 行应在桌上；⏳ 行用 §0.6 替代法）。（判据：件数对得上；缺件登记）
2. **备工具**：§0.5 清单至少齐：内六角 2.0/2.5、小十字起、热熔胶枪、万用表、卡尺（或梯条样片）、5V≥2A 电源＋Type-C 线×2、9 根 28AWG 裸线、M2 顶丝/M3 螺母盒。
3. **三个顺手试配**（全部用手感，不硬压）：① 6806 试 P05/P06 的 42.3 孔、P11 试 Ø29.8 轴段（用梯条 01/02 预判）；② P04 舵盘口袋对 MG90S 自带舵盘；③ LCD 四柱对 P24 的 **77×45**。（判据：都能配上或知道怎么修；配不上先修塑料）
4. **应急件先处理**：P02 裂 / P20 立柱断 → 按 §0.6 胶接/点固，不等重打。

### 阶段 B · 底座电子（P01 杯内 · §1）

5. **麦克风 ×2（P32 胶座）**：INMP441 放入腔（**焊盘凸边朝腔缺口**），模块底孔对 P32 底 Ø6 声孔；rim 只涂外圈热熔胶，罩住 P01 壁 Ø2.4 声孔按压 10s。左右各一，L/R 勿反。（判据：不晃、声孔同心；胶没进声孔）
6. **功放（P17 托盘）**：MAX98357A 入托盘、两孔对 **12.6 距 M2 柱**、M2×4 手拧；接线 Vin 5V / GND / LRC / BCLK / DIN / GAIN / SD；扬声器接**差分 ±**（勿共地）。（判据：板贴平、线不绷）
7. **扬声器（P16）**：**振膜朝前**放入环、EPDM 缘垫、焊片朝后。（判据：手按不晃、振膜不碰壁）
8. **舵机（P15，合并版）**：**先把 MG90S 的线从尾端让位槽（6.8 宽）穿下去**→ 本体滑入口袋 13.7 → 耳孔对架孔 → 自带 M2×2 手带紧**不锁死**（留 ±2mm 张紧）；**底板 M3×6 从杯底锁**（M3×8/10 螺尖会顶线，禁用）。舵盘不装。（判据：能滑动、不晃、线不夹）
9. **停止键（P20）**：开关入口袋（1.8 深），**无论 P20 在不在都热熔胶点固**；两脚各焊一根引线——一根并入底座内的系统地，**另一根就是第 20 步 9 根跨轴线里的"按键"线**：现在只焊线、另一头留着不接，第 29 步进头后才插核心板**空闲非启动 GPIO**。P19 键帽后装。
10. **供电（P18T）**：E17 USB-C 输入板放腔、扎带勒紧、口对 P01 后容差窗 13.5×9.5。E17 缺：5V 从后窗引到**头部**核心板，底座只留舵机 5V，**共地**。（判据：插拔板不位移；舵机电源与核心板不共 3.3V）

### 阶段 C · 传动 / 轴承（P01 中央 · §2）

11. **P05 落底 + 干装量高**：四腿坐 P01 底；把 P06＋4×M3×55–60＋P07–P10 一起**干装**试堆叠，量总高约 **56mm**（M3×70 会多 ~14mm，剪短/垫）。**量完拆散、螺母不上**，正式安装从第 12 步重来。**正式装配前**：4×M3 螺母先放入碗底六角沉坑（塔脚正下方，六角防转），再落 P05 脚——落底后坑被盖住就塞不进；第 14 步的长螺丝从上穿下、直接拧进这些螺母。
12. **下 6806 入 P05**：从座口顶面平放、**拇指只压外圈**均匀加力到"咚"到底、外圈与座口齐平（座底有唇托住）。（紧=砂纸/胶带鼓修孔，勿敲；松=生料带 1–2 圈/薄垫片，仍松少量 CA 点外圈）
13. **P07–P10 四支柱**立四角（方向不分；柱顶面平齐）。
14. **上 6806 入 P06**（从顶面压入、坐到孔底唇上）→ P06 盖柱顶 → **4×M3×55–60 对角序 1-3-2-4**，手指拧不动 **+1/8 圈**即停。（判据：无白痕、不晃）
15. **P11 空心轴**：如走 P03 **路径 1**，先把扩好孔的 P03 从两轴承座之间的侧缝放入；P12 夹环松套在轴底（胶带临时兜住）；轴自上落下穿两轴承内圈——**轴肩（Ø34.5 凸台）坐到上轴承上端面即到底**（此时轴底 z≈26）；轴承坐在圆段不坐 D 面；紧=砂纸磨轴，松=生料带缠轴。
16. **P12 开口夹环**：合拢 → **M3×10/12 穿夹块锁紧**到"手转有阻尼但不卡"。夹环顶面向上顶住下轴承内圈（上止推），别把轴顶起来。**不要用顶丝顶轴**（会顶出坑）。
17. **P03 64T【决策门 · §2-7 详版】**：P03 最终位于两轴承座之间（z41–52），法兰 Ø43.2／座孔 Ø42.3／唇 Ø38.4／D 孔 Ø30.1 vs 轴肩 Ø34.5——**无直接装配路径**。①**路径 1（手工）**：P03 内孔扩至 ~Ø35（磨掉 D 平）→ 第 15 步前侧放进缝隙 → 沿轴滑到驱动 D 平带（z42.2–50.6）正中 → **M2 顶丝**（孔 1.5–1.6 先通毛刺）顶住 D 平面；孔径大靠皮带张力自定心，必要时补开口衬套。②**路径 2（改模型重打）**：P03 改左右对开抱轴式（2×M2 合抱），本步从缝隙合抱。P04：方槽套 MG90S 自带舵盘、**M2 顶丝**锁舵盘轴。（判据：顶丝顶在 D 面不打滑；两轮皮带槽同高 z≈46）
18. **P13 限位摆臂（D 孔键位环 · 无紧固件）**：从轴顶套入**上段 D 平面**，滑到平带下沿即停（z≈61.8；**与 P12 不接触**，模型相距 29mm，旧文"底端连夹环"为误记）。凸耳朝外。合盖前用 **5mm 泡棉**做临时硬挡；合盖后硬挡=撞 **P02 盖内两个固定限位块**（模型 z61.5–64.4）。手转：**±45° 顺滑、48° 碰硬挡**（量角器核对）。
19. **GT2 带**（到货才做）：套 P03/P04 + P15 前后张紧 ±2mm。未到=手转演示，**不硬拉舵机**。

### 阶段 D · 穿线与合婚（§4 顺序铁律）

20. **穿 9 根线**：5V/GND/3V3/BCLK/WS/MIC SD/AMP DIN/SERVO PWM/KEY 先套 PET 护套，穿 **P11 Ø22 孔**（中心 Ø10 禁入区留空）。**先不压端子不焊头，过孔后再焊。**
21. **P02 上盖**：**44mm 中心孔套过线束**，合 P01；限位块对 P13；**4×M3×8/10 对角锁**。（P02 裂/缺 → §0.6）
22. **P14 短颈**：40mm 管套过线束/轴，法兰落在 P02 上；D 孔对 P11 D 平面；**M2 顶丝**锁；**4×M3×8/10** 拧法兰。

### 阶段 E · 头部子装（可离体 · §3）

23. **核心板入 P29**：竖插槽（**1.7 宽、耳槽咬边 0.6、底槽 28.5**）到底不晃，**FPC/USB-C 端朝上**留 10mm；**2×M3** 固于 P23 头底柱。**封头前先插一次 USB-C 线**确认插得到。
24. **LCD 入 P24**：放背面、四孔对四柱（先量柱距 **77×45**）→ P25 从后盖 **4×M2.5×16/18**，**拧到框贴板即停**（过拧压碎玻璃）。（判据：屏面与窗口同心、排针朝 FPC 侧短边）
25. **摄像头组（P26＋模组＋P33）**：① 镜头先对 P24 的 **6.8** 孔试导向（P26 前壁 3.5，镜头凸 4 伸进 0.5~0.7）；② **FPC 朝下先穿过 P33 背板的 6.4×2.5 槽**；③ 模组推入 P26 腔到底；④ 盖 P33（压筋顶模组背面）→ **2×M3×8 自攻**进 P26 背柱（Ø2.5 导孔、柱距 13.9），**拧到板贴背即停**（过拧裂柱）。P26 背面贴 P24 用双面胶/点胶。FPC 禁裁，弯半径≥5mm。
26. **前脸组件**：P24+P25+LCD+P26（含模组+P33）先合成一组，**先不压进 P23**。
27. **P27/P28 隐私滑盖**：P27 贴 P24 前面；**P28 先放进 P27 的导槽**（滑片＋拨片从导轨背面敞口放入、拨片穿过拨槽窗，面板把导轨背面封住后前后都脱不出）——**槽内滑动**，不是盖在上面。（判据：关 0 ↔ 开 11+ 滑到底不脱出）
28. **P19 键帽**按在开关柄上（松了点胶）。

### 阶段 F · 合头与收线（§4）

29. **头**：P23 落 P14 法兰，**4×M3×8/10 对角**；线束从 P11 上端进 P14 内孔（Ø22），从 **P23 颈孔（Ø40.6）**进头，接核心板。（判据：头落座不晃，线不夹在法兰面）
30. **最后压前脸**：把前脸组件压进 P23 前口（**单边 0.3 锥面自锁**）；P24 **无面板螺钉不要打孔**；松动三点少量热熔胶/胶带。
31. **P30/P31 线鞍**：P30 底座侧、P31 头侧；扎带**绕槽不扎紧**。（判据：头转到 +45° 时线束仍塞得进一根手指）
32. **手转 ±45° 二十次**：线不绷不磨、FPC 不断帧、无异响。

### 阶段 G · 上电（§5）

33. **万用表通断档**：5V 对 GND 不短、各信号线对地不短。（**必做，不许跳**）
34. **上 5V**：无发热无异味 → **屏亮 / 摄像出图 / 串口日志**正常。
35. **舵机小角度**动一下：±45° 不卡、不跳齿、不顶挡。
36. **麦/扬声器通路**：录音回放、播报可闻；**停止键按下=停播报**（不是电机急停、不是硬件断麦）。
37. **拍照留证**。26 项表、AEC、30 分钟温升**全部留赛后**，今天不填 TEST_RECORD_TEMPLATE。

## 0.6 今天的两件应急（P02 裂 / P20 立柱断）

### P02（G3p 裂）
- **先干装两半对位**：中心 **Ø44 座圈必须完整**；接缝涂 CA/环氧，压重 30min；外面贴胶带/夹子。
- **加固（推荐）**：从顶板**垂直往下**钻穿接缝、进下圈壁，**4×Ø2**，插一段耗材当定位销，再涂环氧；比只靠胶稳得多。钻时避开 Ø44 座圈和 4 个 P01 螺钉孔；孔要落在 3mm 圈壁内。
- **圈碎缺**：用**上半（顶板）**当座，P14 法兰直接坐在上面；三点热熔胶/胶带定位；若下圈也碎，用 **3mm 厚临时环**（纸板/PLA，OD≈147、ID≈44）垫在 P01 口上；底部用 **5mm 泡棉块**做临时硬挡。
- **座面找平**：胶固化后用直尺/砂纸把 P14 法兰座面找平；法兰不能翘，否则转头会晃。
- **不要**用大量 502 灌缝（脆、流进孔）；**不要**用热熔胶做结构（会蠕变）。
- 重打（今天不追）：正打（接缝圈朝下）→ 树支撑 + **顶距 0.2** + 支撑密度 15–20% + 过支撑降速 50%；或加 0.5mm 接缝倒角；灰料先烘干。

### P20（INTERN2 立柱断）
- 立柱=螺钉座，断了不影响开关；**底座+开关口袋直接热熔胶点固在杯内壁键位**；P19 键帽照装。
- 重打（今天不追）：5mm brim、**Z-hop 0.4**、最小层时间 8s、风扇 100%、立柱区降速；最好在 `build_v6.py` 立柱根部加 **1.5mm 圆角/撑筋**。
- **不要**用支撑包住立柱（会粘死）。
- **预设**：不要用旧的 `EffMeet2-v6 0.20 H2S`（`wall_loops=6` / `support_on_build_plate_only=0`）；按 [PLATE-CARD-P02P20](plates-merged/PLATE-CARD-P02P20.md) 新建 0.16 预设。

## 1. 底座电子（P01 内 · 参照 parts_img/P01.png）

## 2. 传动 / 轴承（底座中心 · 参照 P05/P06/P11.png）

1. **P05 落底 + 干装量高**：P05 四腿坐在 P01 底；P06＋4×M3×55–60＋P07–P10 一起**干装**试堆叠，量总高约 **56mm**（M3×70 会多出约 **14mm**，剪短/加垫）。**量完拆散、螺母不上**，正式安装从第 2 条起。**正式装配前**：4×M3 螺母先放入碗底六角沉坑（塔脚正下方，六角防转），再落 P05 脚；第 4 条的长螺丝从上穿下、拧进这些螺母。

   - **紧**：停，砂纸/打磨鼓修孔，勿敲勿压内圈。

3. P07–P10 四支柱立四角（方向不分；柱顶面平齐）。
4. **上 6806 入 P06**（从顶面压入、坐到孔底唇上）→ P06 盖柱顶 → **4×M3×55–60 对角序 1-3-2-4**：每颗拧到手指拧不动再 **+1/8 圈**即停。常见错：过拧→PLA 白痕/蠕变松脱。
5. **P11 空心轴**：若走 P03 **路径 1**，先把扩好孔的 P03 从两轴承座之间的**侧缝**放入；P12 夹环松套在轴底（胶带临时兜住）；轴自上落下穿两轴承内圈——**轴肩（Ø34.5）坐到上轴承上端面即到底**（此时轴底 z≈26；轴肩=轴的下行止点）。
   - 轴承坐圆段、**不坐 D 平面**；紧=砂纸磨轴；松=生料带缠轴 1–2 圈；不磨轴承。
6. **P12 开口夹环**：两夹块合拢，**M3×10/12 穿夹块锁紧**；锁到“手转轴有阻尼但不卡”。夹环顶面向上顶住下轴承内圈（轴的**上止推**），别把轴顶起来。**不要用顶丝顶轴**（会顶出坑）。
7. **P03 64T【装配决策门 · 实测】**：P03 最终位于两轴承座之间（z41–52）。**实测**：法兰 **Ø43.2**；上下座孔 **Ø42.3**、两道唇 **Ø38.4**；内孔 **Ø30.1 带 D 平**（须沿轴滑入）；轴肩 **Ø34.5**。四条路径全封——上穿：上轴承内孔 Ø30＋轴肩挡；下穿：下轴承＋Ø38.4 唇挡；侧塞：闭合环套不进连续轴；先放齿轮再落轴：轴肩 Ø34.5 > 孔径 Ø30.1。**只能二选一修复**：
   - **路径 1（手工，今天可装）**：P03 内孔扩至约 **Ø35**（磨掉 D 平、成全圆）→ 落轴前从侧缝放入 → 轴落下时轴肩从孔中穿过 → 沿轴滑到**驱动 D 平带（z42.2–50.6）**正中 → **M2 顶丝**（孔 1.5–1.6 先通毛刺）顶住 D 平面。孔径大、侧隙约 2.5mm：靠皮带张力自定心；仍晃可补打印开口衬套。
   - **路径 2（改模型重打，约 1–2h）**：P03 改**左右对开抱轴式**（2×M2 合抱），本步从缝隙合抱、对位 D 平面。P11/P06 一字不动。
   - **判据**：顶丝顶在 D 面、手转齿轮能带动轴不打滑；两轮皮带槽同高 **z≈46**。

9. **GT2 带**（到货才做）：套 P03/P04 + P15 前后张紧 ±2mm；未到=手转演示，不要硬拉舵机。

## 6. 常见坑（速查）

- **顺序**：线 → P02 → P14 → 头 → P24；P02 在 P14 之前，P24 最后。
- **P24 没有面板螺钉**：锥面自锁 + P25 压框；不要按 R1 打孔。
- **P05/P06 是同一组 4×M3**：不是“落底一组 + 长螺钉一组”；M3×55–60，底部螺母。
- **P03 装配门**：内孔须扩到 ~Ø35（路径 1）或改对开件（路径 2），否则**任何顺序都装不进去**；详见 §2-7。
- **P03/P04 顶丝 M2**：孔 1.5–1.6，不是 M3。
- **P13 是 D 孔键位环**：套轴**上段** D 平面、靠平带下沿定位（z≈61.8），**无紧固件、不连 P12**；48° 硬挡撞 P02 盖内限位块；P11 D 平面朝上。
- **松配合**：生料带/薄垫片/少量 CA；紧=砂纸/打磨鼓修塑料；轴承不敲、不扩、不磨内外圈。
- 螺钉对角序、贴合即停 +1/8 圈；PLA 过拧必蠕变。
- 麦随头转=产品缺陷；麦永远固定底座。
- FPC 裁了=报废；14mm 是硬约束。
- 胶只涂 rim/点固，别堵声孔别灌腔；P20/P32 都要胶。
- 替身颈（PETG）与正式颈（黑）D 面/顶丝通用，换装只卸顶丝。
- 扎带扎紧=线束疲劳断；留 1 指。
- **P02 裂**：先胶接/上半做座；**P20 立柱断**：底座+热熔胶，别等重打。
