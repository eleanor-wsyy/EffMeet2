## 打印设置

- 0.16–0.2 层高、4 墙、25–30% 填充（Gyroid）、无支撑（螺耳下沿小悬空可桥接；如塌陷再给螺耳加树支撑）
- 平放：法兰面朝下、Z 向上（与导出的姿态一致）；3–5mm brim 可选
- 材料：灰/黑 PLA 均可（与现有齿轮同料最好）

## 装配

**路径 1（P03 扩孔 + 衬套）**：衬套从开口处卡到轴的驱动 D 平带上 → P03 侧放进两座缝隙 → 落轴时衬套随轴进 P03 孔 → 顶丝压住衬套锁死。

**路径 2（对开齿轮）**：
1. 半 B（含 D 平）先贴到轴驱动带，让内孔 D 平对正轴的削平面；
2. 半 A 从另一侧合上，四只螺耳对齐（B 在下层、A 在上层各两处）；
3. 用 **M2×6 自攻螺钉**（马达盒里自带的那种）从 A 侧过孔拧进 B 侧底孔，两颗拧到贴合即停（别过拧滑牙）；
4. 回装 P03 原有 **M2 顶丝**，顶住轴 D 平；
5. 判据：手转齿轮能带动整根轴、不相对打滑；两轮皮带槽同高 z≈46。

## 风险与记录

- 路径 1：手工扩孔精度要求高（目标 Ø35，肩台 Ø34.5 需穿过 P03 孔，留 0.5 间隙）；侧隙靠衬套+顶丝消除。
- 路径 2：两半为 3D 打印件，抱紧力来自 2 颗 M2 自攻；螺耳为悬臂结构，拧的时候别暴力。
- 两条路径都请在实装后把结果（成功/失败点、实测间隙）记到 `../HANDOFF.md` 与 `MEASUREMENTS.csv`。
