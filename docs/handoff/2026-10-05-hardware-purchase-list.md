# 硬件采购清单

型号尚未冻结，采购前按板卡版本核对接口、电源和套装内容。

| 物料 | 数量 | 要求 |
|---|---:|---|
| ESP32-S3 音频板 | 1 | 带 PSRAM、采集与播放路径；项目参考 Korvo-2 |
| 麦克风或麦阵列 | 1 套 | 板载已有则不重复买，匹配 Codec 与驱动 |
| 扬声器 | 1 | 阻抗、功率及插头按板载功放选 |
| 功放 | 按需 1 | 板载已有则不重复买 |
| USB 数据线及电源 | 各 1–2 | 支持烧录，供电满足板卡及峰值负载 |
| 摄像头及排线 | 1 | 核对接口引脚和驱动，不能只凭 OV2640 名称判断兼容 |
| 接线及固定辅料 | 1 套 | 接插件、铜柱、螺丝等 |
| 单轴舵机与支架 | 各 1 | 按头部重量选扭矩；SG90 通常为塑料齿轮 |
| 静音按键、状态灯 | 各 1 套 | 停止播放和状态显示 |
| 稳压及供电分支 | 按需 | 避免舵机导致音频噪声或复位 |
| 外壳 | 1 | 音频和机构验证后确定尺寸 |

先采购音频板及配套扬声器、电源、线材，再补摄像头，最后采购舵机和外壳。

## 供电与验收

开发阶段优先用符合板卡要求的 USB 电源或充电宝，检查充电宝自动关断。干电池须经过适配板卡的稳压模块；不能按电池节数保证稳定 5V，不能将未经稳压的电池组接到 3.3V 引脚。加入功放和舵机后测峰值电流、压降和底噪，再确定电池系统。

验收顺序：烧录日志 → 拾音 → 播放和停止 → Wi-Fi 音频及回执 → AEC 回声参考与双讲 → JPEG 抓拍 → 舵机与整机。软件播放互斥不等于 AEC，需真实声学环境验证。

暂不采购成品机器人、复杂云台或大功率会议音响。
