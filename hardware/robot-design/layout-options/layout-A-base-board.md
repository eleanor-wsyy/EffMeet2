## 3. 验收要点（本方案特有）

| 项 | 通过标准 | 说明 |
|---|---|---|
| **过轴 FPC 寿命** | 连续 50 次 ±45° 转向无断屏/断帧/断线 | **本方案第一验收项** |
| 夹线 | 转动全程不夹线、不磨线 | 软限位 + 硬挡都要查 |
| 头部重量 | 比 B 轻，SG90 转向 1–2s、头角误差 ≤3° | 首轮目标，非已实现性能 |
| **麦克风拾音** | **底座固定双麦**，1m 正常说话可转写、3m 小声触发 AGC | C06 按底座孔位，不随头转 |
| AEC | 重测（换板必做） | 初赛不阻塞，决赛 11.5 前必须 |
