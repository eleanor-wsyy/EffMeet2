# EffMeet2 · 新版安装指南（NOMI／布局 A／v4）

更新：2026-10-11（北京时间）。采购入口仅用 [BOM §12](BOM.md#final-purchase-decision)，尺寸来源仅用 [parameters.json](parameters.json)。本轮模型、图纸入口见 [v4目录](revision-20261011-nomi-layoutA/README.md)。

**方案冻结：GOOUU ESP32-S3-CAM（套装内OV3660） 主板固定在底座；头部只有 LCD、可拆摄像模组和隐私盖；固定双INMP441；侧置位置舵机＋双6806轴承＋1:1传动；±45°；灰／黑 PLA Matte 裸打。** AI 和会议逻辑由电脑伴侣承载（路线 A）。

**本指南是新版装配顺序，不是已经装好的验收报告。v4为可逆工程封装候选，头颈接收几何已建入，但螺钉／螺母接收、公差、轴肩、舵盘、FPC规格仍需样件锁定；不得拿任何旧草案文件打印整机（旧 stl/ 已于 2026-10-12 删除）。**

## 2. 电气和机械安全

- 穿排线、接锂电、装机构或调整传动之前，主板和舵机电源均断开。
- **禁止裁剪 FPC／FFC 来改长度。** 使用接触端完整、针序／间距／接触面一致的线或厂家延长组件；多余部分仅在允许弯折半径内走宽缓路线，不能折死或塞进轴承。
- 显示线束和摄像FPC 需同时通过Ø22空心轴。主板、舵机、停止键和灯固定在底座，因此其电源／PWM／按键线**不用跨轴**；不多塞无功能的活动线。
- 舵机用符合实物额定值的独立稳压电源。信号共地，不并联独立5V正极，不从ESP32的3.3V给舵机供电，不直接把3.7V电池当5V舵机电源。
- **若复用BOOT/G0，按下时复位／上电可能影响启动模式，必须做T22测试；GPIO不能只因排针上存在就认为可用，先核摄像／屏／I2S／PSRAM／启动占用。停止播报键不是电机急停、不是硬件断麦。** 初次带载测试必须能直接切断舵机供电。
- 不锤压轴承、不强扭通电舵机，不让打印壳／屏玻璃承担夹紧预载；PLA采用螺接和受力肋，不依赖薄弹性卡扣。
- 电池装在固定绝缘托架内，不穿刺、不挤压，不把热装嵌件操作放在电池附近。充电／保护接法由实际板版本、外置充电模块和电池说明确认。

## 3. 按风险顺序装配

### 01 · 裸板联调，先证实电子链路

1. 记录主板版本、屏幕SKU、摄像模组、线材定义、固件提交；只接经确认的接口。
2. 台架分别验证屏点亮、摄像出帧、固定双麦拾音、扬声器播放和停止键。
3. 接上两条拟跨轴线材，仍在静止台架验证画面和屏幕；不把厂商demo当成项目会议闭环。
4. 外接INMP441×2先确认供电、L/R和I2S同步；MAX98357单独播放验证。先不接电池、不挂头、不封壳。缺驱动／线材就标BLOCKED，不进入大壳打印。

### 02 · 配合样片和正式料样片

1. 现有PETG用于1:1孔径、轴肩、舵盘接口和滑槽试片。
2. 再用正式PLA Matte验证配合；PETG合适不能直接证明PLA也合适。
3. 实物表、孔径档、螺钉长度、插头空间、支撑可拆性写回参数后，才进入正式件。现有四件样片仍是试验输入，旧整机STL不是v4放行文件。

### 03 · 固定底座与电子件

1. 杯口朝上放稳，检查四条前出声槽、后通风槽、固定麦孔及供电出口真实贯通。
2. 按新版竖置方式安装后部GOOUU核心板。套装扩展板未量尺寸，当前模型不把它算入放得下；可先作台架联调工具，到货后再决定是否省接线复用。安装柱和绝缘垫片对真实孔位定位，Type-C插头、插拔手指、天线前方均留空。
3. 两只INMP441固定在后部上缘（候选中心X±16.3、Y69、Z52），声孔／软密封按实际模块端口配作；图中的对称孔是候选坐标，未实测前不得声称已对齐。麦仍固定在底座，不随头转。
4. MAX98357A装在前右预留区，再接前部扬声器。扬声器接模块差分输出，不把负端接地；I2S引脚／供电按实际模块定义。振膜对四条声槽，软垫密封不堵出声口。电池固定在右下独立绝缘区域；导线远离同步带。
5. TP4056仅作充电／保护，不是5V升压或自动边充边用管理；Demo仍外置稳定5V，电池路径另验。主板供电线和舵机供电线从固定底座后部走，外部线不跟着头转。后出口是线／插头维护开口，不假装Type-C母座直接位于外壁。前肩按钮需要其下的真实外接开关；不设计100mm连杆去硬推后部BOOT。

### 04 · 双轴承支撑和传动

1. 两只轴承装入分体螺接夹持座；上、下座必须有真实承力路径固定到底座，不把模型中的座包络视作已完成螺接结构。
2. 空心轴按实物配合样片定位，确认轴肩／锁圈承担轴向力。不能仅凭29.8mm轴包络和30mm名义内径宣称配合正确。
3. 舵机空载校准、断电，再安装原配舵盘和螺接适配件；不自行打印未测花键。
4. 同齿数传动与Ø30空心轴核算后选带轮：v4用64T包络避免小齿数轮根本套不进空心轴的错误。228mm只是候选节线长，实物带长和张紧行程未锁定。
5. 手动低阻检查（断电、必要时脱开舵机），正常目标±45°不碰硬挡；硬限位必须位于夹线／碰撞边界内，不能靠反复堵转限位。

### 05 · 两条 FPC 过轴，先穿线再装头

1. 从固定主板开始标LCD／CAMERA；屏为套装J2 14针，触摸可能要额外信号。端接最大截面对角需小于实际Ø22通道；分两组7芯仅是候选，实装后再定。摄像FPC禁止裁剪。
2. 两条线进入Ø22通道，避开轴承滚动面、轴肩和紧固件。两端固定，活动区不固定死，接触边去毛刺并配软护套。
3. 在未封头状态先检查左45°／0°／右45°各姿态，再上电小幅低速移动。
4. **几何有空间不等于 FPC 可长期扭转。** 实际最小弯折半径、延长信号完整性和50循环同时满足后，才能认定布局A跨轴方案成立。

### 06 · 头部屏幕、摄像头和圆黑面板

1. 先把LCD装在可拆承托支架上，由PCB／非光学边框定位，玻璃不承受螺钉预载；真实固定孔和支架仍需实测。
2. 再装摄像模组，镜头对圆脸上部。候选镜头坐标只控制外观意图，最终开孔服从实际模组和支架，不移动实板麦克风来换对称。
3. 面板是Ø106哑光黑打印件：中央58.2×43.8贯通窗、背部屏边让位、上部镜头孔。不采购整片透明罩。
4. 屏面目标略低于打印面约1mm，避免玻璃突出。背面让位后约1mm薄边需要PLA样片复核；不以喷漆／打磨补救错位。
5. 隐私滑盖必须有真实导向、行程止挡和防脱结构；图中开位仅为布局代理，不能证明它能滑或完全遮住镜头。
6. 面板从前口拆装，确认螺钉工具可达后再封；维护时无需拆主板。v4新增3.2mm头底接收面、隐藏法兰和两处M3候选孔；螺母接收／长度／工具空间需样件锁定后再打正式头壳。

### 07 · 短颈、按钮、灯和收尾

1. 保留头壳最低Z92、底座最高Z78：**真实竖向间距14mm**。Ø46短颈通过Ø48盖孔，名义径向间隙1mm不能代替打印公差试验。
2. 短颈与头部一起转，不与固定底座粘死；装饰不能遮盖显示线束和摄像FPC活动区。
3. 按钮帽与实际开关行程配作，松手不能常压；前短划LED需要真实光路／引出方案，不能因渲染发光而记测试PASS。
4. 先做入壳联调，再拧上盖螺钉；检查不夹线、不压电池、不堵麦／声孔，最后贴约2mm现成硅胶脚垫。

## 4. 组装后测试与交付

执行 [TEST_GUIDE](TEST_GUIDE.md) 全部T01–T26，用 [空白记录模板](TEST_RECORD_TEMPLATE.csv) 保存实测。优先顺序：

- **T04／T05／T06**：真实矩形屏两只眼睛在有效区内，镜头视场、隐私遮挡与可拆修。
- **T12／T14／T15**：独立承重、±45°、50循环，两条排线不断屏／断帧、不夹线。
- **T07／T08／T16／T17／T25**：固定麦与声槽入壳复测，舵机噪声不得破坏会议拾音；缺AEC记录BLOCKED，不制造PASS。
- **T09／T10／T18–T23／T24**：真实停止／指示／本人确认／回执与故障恢复、30分钟组合运行、质感与稳定性。
