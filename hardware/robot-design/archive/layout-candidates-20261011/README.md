## 布局 B 被否决的理由（备查）

1. **麦克风随头转**——拾音特性随头角变化，ASR 准确率变成头部朝向的函数；而机器人转头的时刻恰是最需要稳定拾音的时刻。
2. 推翻既有产品规则（`BOM.md` C06）：「麦克风不随头转，不能宣称通过转头实现指向性拾音」。
3. 头部加重，SG90 带载吃紧，宠物形态的灵动性下降。
4. 代价性质不对等：A 的代价是工程努力（两条排线 + 过轴寿命验证），B 的代价是产品功能缺陷（拾音不稳，修不了）。
