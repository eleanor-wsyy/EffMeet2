## 1. 气质基调（和产品语言同源）

产品承诺是"温和干预、未经确认不开口"——外形必须把这句话说出来：

- **抽象形态，不做仿生物**。不画猫狗五官、不做毛绒、不做大眼睛卖萌——那些会把"会议工具"读成"玩具"，评委一眼看穿廉价感。参照 Loona / EMO 的抽象路线：圆润的蛋形小柱，正面一块小表情屏，仅此而已。
- **安静感 > 存在感**。坐姿微微内收（底部略窄于肩部），常态只有一枚低频呼吸的状态光。它 90% 的时间应该让人忘记它在桌上。
- **诚实感**。摄像头、麦克风、状态光的位置全部外露可见，不做隐藏式开孔——隐私不是藏起来，是看得见。

## 2. 表情与状态语言

正面表情屏（小尺寸 OLED/IPS 圆角矩形，约 40×40mm 视区）+ 顶部环形状态灯，二者分工：

| 状态 | 表情屏 | 环灯 | 时机 |
|---|---|---|---|
| idle | 闭眼 / 低频眨眼 | 白·呼吸（4s 周期） | 会外/会后 |
| listening | 睁眼平视 | 橙·常亮微光 | 会议中录音 |
| analyzing | 眼睛向下看 | 蓝·慢闪 | 千问分析中 |
| pending_confirmation | 眼睛看向远程成员方向 + 眉微抬 | 橙·双闪 | 候选等待本人确认 |
| speaking | 嘴部简笔动势 | 橙·流水 | 播报中 |
| error | 眼睛变两条横线 | 红·慢闪 | 断连/降级 |

表情素材属 `assets/face/`（D 的地盘），此处只定义状态-表情的映射关系。规则三条：

1. **播报前必须有 0.8 秒"请示态"过渡**（pending → speaking 不得瞬切）——物理上对应安全停顿复核
2. 表情永不出现在屏幕上卖萌撒娇的动作（捂嘴、委屈、星星眼一律禁止）
3. error 状态表情要"平静地坏掉"，不要警报感——降级是设计能力，不是事故

## 3. 尺寸与桌面占位

- 整机约 **90 × 90 × 110mm**（含底座），小于马克杯占位；桌面参会时不遮挡任何人与白板之间的视线
- 重心压底（电池/配重在下），单轴转头 ±120° 不倾倒；转轴阻尼要让"转头看人"的动作慢下来（0.6–1s 完成一次转向，显得从容，不是警觉）
- 底部：环形硅胶垫，玻璃/木桌均不滑；走线从背后出线（USB-C），桌面看不到线

## 4. 材质与工艺

- 主体：哑光 ABS，**米白**主色（暖白，不是冷白），品牌橙仅用于状态灯与按键点缀
- 表面细砂纹（30–40μm），不反光、不收集指纹；接缝沿背部中线，正面无缝
- 演示样机允许 FDM 3D 打印，但层纹必须打磨+补土+哑光喷漆处理；量产意象按 CNC/注塑写

## 5. 硬件对应（与 B/C 对齐）

| 部件 | 外壳处理 |
|---|---|
| ESP32-S3 主控 | 内仓，背部散热缝 |
| 摄像头 | 正面上部外露，**配物理遮罩拨片**——拨下可见镜头被挡，隐私明示，评委问答时的加分点 |
| 麦克风 | 顶部微孔阵列，远离扬声器轴向 |
| 扬声器 | 正面下部点阵开孔，出音朝向桌面微微上扬（近场清晰、远场不吵） |
| 单轴舵机 | 颈段，转头模块与肩线一体成型，无外露线束 |
| 物理静音键 | 顶部大键，行程长、有明确段落感；按下时**硬件级断开麦克风**且环灯转红——静音是物理承诺，不是软件状态 |
| USB-C 供电 | 背部下沿，带浅凹槽防拽脱 |

## 6. 给演示视频的三个镜头建议

1. 开场：机器人呼吸光中的桌角空镜（安静感）
2. 候选确认时刻：特写表情屏"看向远程成员 + 眉微抬" + 环灯双闪（分寸感的可视化）
3. 隐私问答：手指拨下摄像头遮罩（诚实感）
